# The directives of the fidelity suite that Wasmtime fails, run
# through the Wasmtime backend of the runtime layer.
#
# One entry per line: `<script>:<line> <citation> <reason>`. The script is
# its path under the root of the pinned specification test suite, and the
# line is the directive's, counted from one. The citation names the defect
# of Wasmtime that explains the failure: an issue of
# bytecodealliance/wasmtime, or a line of its source at a fixed commit. An
# entry without a citation fails the check, and a feature whose failures no
# defect of Wasmtime explains is not a capability the backend declares.
