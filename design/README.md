# Project Design Documents

This directory contains a sequence of Project Design Documents (PDD)
that collectively represent the historical design choices that produced
the project.

General guidelines:

- **Open with a concise introduction to the design**
- **Include a "Goals" and "Non-goals" section**
  - The bullets in these sections should be as concise as possible, with
    any elaborations spared for the body content of the PDD
- **Represent featureful improvements with user stories**
  - User stories should prefer to center human persons over software,
    programs and synthesized intelligences whenever possible
- **Include a references section** that enumerates external links
  related to or sourced by the immediate document
- **Use the most direct link possible** when referring to specific content
  within references or other PDDs
- **DO NOT suggest concrete program implementations or project directory
  structures**
  - These should be decided during engineering planning after the design
    is considered
  - Psuedocode and flexible / non-specific suggestions are always welcome
- **DO NOT pre-empt future design documents by referencing them or
  anticipating their contents contemporaneously**
  - If something is not in scope or will be covered later, add it to the
    "Non-goals" section
- **DO NOT leave lingering open questions unanswered!**
- **DO NOT make references to project implementation or ongoing work streams**
- **Make an effort to follow the format, structure and idioms of the
  design documents that have already been accepted!**
