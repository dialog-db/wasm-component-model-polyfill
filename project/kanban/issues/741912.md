## What to build
Map `Trampoline::TaskReturn { instance, results, options }` in `src/executor/translate.rs` to a `TrampolineSpec::TaskReturn` in `src/executor/ir.rs` carrying the projected result type (one result or none; more than one is `Error::Unsupported` as today), the lifted `CanonOptions`, and the core signature, which is the flattened result or one pointer when the flattened result exceeds sixteen values; build it in `src/executor/instantiate.rs` with the other specs. The built-in resolves the current task (`TaskTables::current_task`) and traps in the reference's order: the cannot-leave cause when the instance record's `may_leave` is clear; the return-from-synchronous-task cause when the task's lift options are not `async_`; the return-mismatch cause when the built-in's result type differs structurally from the task's function result, or its string encoding differs from the task's options, or its memory differs from the task's memory by identity, where a built-in whose options name no memory passes when the result needs none. It then lifts the result through one `BoundaryContext` built from the built-in's options, the instance, and the task, so a string or list result reads the task's memory; then traps with the returned-twice cause when the task is already resolved and with the outstanding-borrows cause (the `AbiCause` the exit intrinsic uses) when the task's borrow count is above zero; then `Task::resolve` stores the value. No host call reaches a task that may return yet, so prove the traps with in-crate tests that create a task with `async` options through the store's records, push it as the current scope, and call the built-in's function; prove the synchronous case on a component written by hand.

## Acceptance criteria
- [ ] `canon task.return` translates, and the component of `task-builtins.wast` that defines only `task.return` instantiates and its line leaves the list.
- [ ] A `task.return` from a synchronous export fails with the return-from-synchronous-task cause, proved on a component written by hand.
- [ ] With a task whose lift is `async` created through the store's records: a mismatched result type, a mismatched string encoding, and a mismatched memory each fail with the return-mismatch cause; a built-in whose options name no memory passes when the result needs none; a second return fails with the returned-twice cause; a return with an outstanding borrow fails with the outstanding-borrows cause; a string result lifts through the task's memory.
- [ ] The built-in fails with the cannot-leave cause when a realloc calls it, proved by a test.
- [ ] `tests all` passes on both targets, and any async directive that starts passing has its line removed from the expected-failure list.
