## What to build

PDD028, "The Code for One Interface" and "Imports" for plain functions, and the `imports` option. Generated traits and registrations for imported plain functions, with Wasmtime's names (`crates/wit-bindgen/src/lib.rs:2978-3052` at `v49.0.0-rc.1`).

- **Traits.** For each imported interface, `Host` (one method per plain function without the `store` flag) and `HostWithStore<T>: HasData` (one method per function with the `store` flag, taking `Access<T, Self>`). World-level imports get `{World}Imports` and `{World}ImportsWithStore<T>`. The host implements `Host` on the projection's result and `HostWithStore<T>` on the `HasData` type. Emit Wasmtime's `&mut T` forwarding impls, and honour `skip_mut_forwarding_impls`.
- **Registration.** `add_to_linker_instance`, `add_to_linker`, and `add_to_linker_imports`, each taking a projection `fn(&mut T) -> D::Data<'_>`. A registration calls the projection, then the trait method, through `func_wrap`. A versioned interface registers under its versioned name. A `store`-flag registration builds the `Access` from the `HostCall`. `require_store_data_send` adds the `Send` bound natively and has no effect in the browser.
- **Flag rules.** The `imports` option with Wasmtime's matching (`config.rs:95-159`): the first matching rule applies, a rule that matches no function fails the compile, `[drop]r` names a destructor, and `default` applies last. Flags here: `trappable` (returns `wcmp::Result<T>`, an `Err` traps), `exact`, `tracing`, `verbose_tracing`, and `store`.
- **Refusals.** `async` on a plain import, alone or with `store`, fails the compile. The message names the missing host function that holds the store across an await and suggests `async func` in the WIT.
- **`ownership: Owning`.** Accepted as the default.

Generated `@unstable` imports get their trait method and registration.

## Acceptance criteria
- [ ] A generated import takes a variant and a flags value and returns a record, and the guest receives the record the test expects, on both targets.
- [ ] A host error from a generated method traps the guest: a `trappable` method returns `Error::Host` with a source of a host type, the guest traps, the host's call returns an error whose source downcasts to the host type, and the store is poisoned.
- [ ] A plain import with the `store` flag creates a future: a method with the shape of `wasi:webgpu`'s `lost` receives an `Access`, creates a `FutureReader` through the store context, and returns it. The guest reads the future's value, on both targets.
- [ ] A WIT world with an `@unstable` import generates its trait method and its registration, and a component that does not import it links.
- [ ] An `imports` rule that matches no function fails the compile, and the first matching rule wins over a later one.
- [ ] `imports: { default: async }` and `imports: { default: async | store }` fail the compile; the error names the flag and suggests `async func`.
- [ ] `lint` passes, and `tests all` is green on both targets with the conformance summary unchanged.
