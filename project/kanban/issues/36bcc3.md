## What to build

PDD026, "Browsers". The demo runs in current Chrome and current Safari. A person runs it in Epiphany, which stands in for Safari, because the test lane runs only headless Chrome. Safari before 27 has no JSPI, and there the polyfill uses nested turns.

A person serves the demo with the menu command, opens it in Epiphany, completes the TodoMVC behaviors by hand, opens the drawer, and saves one element edit and one route edit. The person records the browser version and the result in the demo lane's report. A failure becomes a new bug card.

## Acceptance criteria
- [ ] The demo runs in Safari. A person opens the demo in Epiphany and completes the TodoMVC behaviors by hand. The person records the result in the lane's report.
- [ ] One element edit and one route edit apply in Epiphany, and the report says so.
