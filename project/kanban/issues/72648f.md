## What to build
Two gaps the independent review of card 264c89 found in the polyfill's Zena runner (landed as `b882bd371`). Neither blocked the card.

- **The development shell.** `tests/zena.rs` embeds the scenario bundle with `include_bytes!(env!("WCMP_ZENA_SCENARIOS"))`. The test archives and the clippy check set the variable; the development shell does not, so `cargo clippy --all-targets` and rust-analyzer fail on `zena.rs:51`. Make the development shell work without building Zena on entry, for example with an empty bundle or a clear opt-in.
- **Bundle tests.** `tests/zena/bundle.rs` has no tests for a header that is not UTF-8, a bad length, a bad status, or a missing `.wasm` for a status-0 program. Add them.

## Acceptance criteria
- [ ] `cargo clippy --all-targets` inside `nix develop` no longer fails on the missing variable, and entering the shell does not build Zena.
- [ ] Each malformed-bundle case above has a test that fails when its check breaks.
- [ ] `tests native debug` and `tests web debug` pass.
- [ ] `lint` passes.
