## What to build
Two small clarity fixes the independent review of card f3f4c8 found in the Zena scenario build (landed as `781501750`). Neither blocked the card.

- `rust/wcmp/tests/zena/build.sh` changes into each scenario directory and then writes under its output path, so a relative output path fails with "No such file". The only caller passes an absolute `$out`. State in the script's header that the output path must be absolute, or resolve it to an absolute path at the start.
- The error thrown when the `zena` input has no revision (`flake.nix`, `zenaRevision`) recommends a `git+file://…?rev=` override. Under such an override, the `zena-scenario-build` check still fails, because `flake.lock` holds the pinned revision. Say so in one line of the message, and point at `nix flake update zena` for moving the pin.
