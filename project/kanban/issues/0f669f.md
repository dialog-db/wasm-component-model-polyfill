## What to build

PDD026, Goals and "Test Cases". A browser test lane that drives the served demo in headless Chrome, and its place in `tests all`. Later demo cards add their tests to this lane.

- **Runner.** Serve the built demo and drive it with the flake's Chrome and ChromeDriver over WebDriver. The tests reach into shadow roots.
- **Tools the later tests need.** Stop the service worker (Chrome DevTools Protocol `ServiceWorker.stopAllWorkers` or an equivalent), watch network requests and their response headers, emulate the light and dark color schemes, and clear the origin's IndexedDB between tests.
- **Menu.** A menu command runs the lane (for example `tests demo`), and `tests all` runs it. Add it to `.github/workflows/test.yml` with the other lanes.
- **Report.** The lane writes a short report that a person can add to by hand. The Safari check records its result there.
- A first test loads the page and waits until the service worker controls it.

## Acceptance criteria
- [ ] The demo lane runs in `tests all`. A failure in the lane fails `tests all`.
- [ ] CI runs the lane through the same menu command.
- [ ] The lane can stop the service worker, read network responses, set the color scheme, and clear IndexedDB. Each tool has one test that uses it.
- [ ] `tests all` and `lint` pass.
