## What to build

Non-blocking findings from the independent review of 7eb780 (the switch, landed `faf3e8510`), in `rust/wcmp`:

- **Destructor errors lose their type.** `trampoline.rs:268-269` wraps a guest destructor's `RuntimeError` with `.context` and no `into_anyhow`. `TrapKind::Host` is `#[error(transparent)]`, so a polyfill `Error` raised inside a guest destructor can no longer be downcast. The sibling path uses `into_anyhow` (`store_context.rs:347-358`).
- **A dropped instantiation leaks reservations.** `instantiate.rs:226-233` withdraws `ReservedRecords` only on `Err`, and it has no `Drop`. Now that instantiation awaits (`:474`, `:689`), dropping the future mid-await leaves reserved records and names in the store, which breaks `linker.rs:190-198`.
- **First-stretch trap fidelity.** A trap in the first stretch of a resumable call started in place inside a host function gets a generic `TrapKind::Other` (`host_suspension_provider.rs:609`), and a structured host error on that path is lost; `reentrancy.wast:114` would pass without it. This needs the layer to report that trap to a non-awaiting caller.
- **Native untyped call.** Native untyped `u32-call` went 1.44 → 2.10 µs in the reviewer's paired runs (typed is equal). Explain it and recover it if it is cheap.
- **`Store::new` requires `T: Send` natively** (`store.rs:177`), a public API tightening the card never discussed. Document it, or lift it.
- **Wasmtime backend handle tables** grow by about 3 slots per prepared call and are never freed; add a test and a fix.
- **Stale text.** `lib.rs:144-146` still says the polyfill owns its substrate selection; `expected-failures.txt:42` keeps a stale reason for the component-level GC-ref refusal (`component/project.rs:305-346`), which may now be removable; the corpus README baseline figures are dated 2026-09-27.
- **Missing tests.** An end-to-end run of the host-suspension provider natively through components on Wasmi; a nested in-place start that traps with a host error in its first stretch; a dropped instantiate future; downcasting a destructor's structured error.
- **Menu gap.** No menu verb runs the web bench with the host-suspension provider off.
