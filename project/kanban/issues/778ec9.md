## What to build
Replace the `&mut T` first parameter of typed and untyped host closures with a polyfill-owned `HostCall<'_, T>` that exposes `data`, `data_mut`, and `resource_new` over the per-store handle tables. Update every registration call site and test. Un-stub `it_lets_a_host_function_mint_a_resource_handle_during_a_guest_call`.

## Acceptance criteria
- [ ] `func_new` and `func_wrap` closures receive `HostCall<'_, T>`.
- [ ] `it_lets_a_host_function_mint_a_resource_handle_during_a_guest_call` passes on every target.
- [ ] Minting against an unknown resource type identity surfaces `AbiCause::UnregisteredResourceType`.
- [ ] No runtime layer type appears at the closure boundary.
