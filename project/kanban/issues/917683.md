## What to build

Proposed issue text:

> The C generator still declares six `[cancellable][thread-*]` imports in the
> async header (`crates/c/src/lib.rs:754-778` at `dd35352`). The component
> model removed the `cancellable` immediate in WebAssembly/component-model#716.
> wit-component 0.261 accepts only the bare names, so a guest that calls one of
> these declarations fails to componentize ("no top-level imported function",
> `validation.rs:788`). wit-bindgen itself depends on wit-component 0.262. The
> declarations can be removed.
