## What to build
From the 2026-10-13 review of a70072 (and its absorbed card 2e6717). The typed direct path for a numeric `Vec<T>` is not reached when parameters spill.

- The typed spill test uses `(String, [u32; 8], [u32; 8])` (`rust/wcmp/tests/baseline_typed_direct.rs`). `String::store` takes the direct path, but `[T; N]` uses the default `store`, which goes through `to_val`.
- The direct numeric branch of `Vec<T>::store` (`rust/wcmp/src/linker/component_value.rs`, the `write_pointer_pair` call) is reached by no test. Checked on 2026-10-13: passing `0` instead of `len` to `write_pointer_pair` there, `tests native debug` passed all 1733 tests.
- Fix from the review: use `(String, Vec<u32>, [u32; 8], [u32; 8])` (20 flat values), and have the guest fold the vector too.

Also from the same review, smaller:
- The UTF-16 typed echo test round-trips through a guest that echoes the pointer and length, so a typed mistake that used UTF-8 both ways would still pass. A guest export that returns the length word it was given would make the test independent.
- The two typed `call_concurrent` calls run one after the other. Make them overlap.
- `rust/wcmp-bench/README.md`: the `list-record-roundtrip` row says "the same", which now refers to the new typed row above it. That benchmark is untyped.

## Acceptance criteria
- [x] A typed call whose parameters spill carries a `Vec<u32>` (or another numeric `Vec` wider than a byte) through the direct `store` branch, and the test fails when that branch writes a wrong length.
- [x] The UTF-16 typed test fails if the typed path used the wrong encoding.
- [x] The typed concurrent test has two calls in flight at once.
- [x] The bench README row is correct.
- [x] `lint` passes and `tests all` is green on both targets.

## Implementation notes

- 2026-10-13 (`test(typed): Reach the direct Vec store, tell encodings,
  overlap calls`):
  - `spilled` is now `(string, list<u32>, list<u32, 8>, list<u32, 8>)`
    (20 flat values). The guest folds the vector's length (times 100000)
    and each element by place. Mutation: `write_pointer_pair(.., 0, ..)` in
    `Vec<T>::store`'s direct branch fails the test (10239 against 310513).
  - New exports `length-utf16` and `length-latin1-utf16` answer the length
    word the guest received. The test expects UTF-16 units, Latin-1 bytes,
    or UTF-16 units with the tag bit, for text beyond ASCII. Mutation:
    `string_encoding()` answering UTF-8 everywhere lets the echo round
    trip pass, and the length check fails (`length-utf16: café crème`, 12
    against 10).
  - The concurrent test pins both `call_concurrent` futures and polls them
    in one `poll_fn` until both finish.
  - Bench README: `list-record-roundtrip` reads "an untyped list with a
    two-field record per element".
