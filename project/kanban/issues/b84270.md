## What to build
Build `wasm-tools` (from nixpkgs) and `wac-cli` (from crates.io, through `lib.rust` or `buildRustPackage`) as flake packages. Add a `fixtures` menu command that regenerates the checked-in fixtures reproducibly: a guest built with `wasm-tools component new` from a core module and its WIT, and a composition of two such guests built with `wac plug`. Check the fixture binaries in with their WIT and the exact commands, and run them under the conformance harness as PDD016 describes.

## Acceptance criteria
- [ ] `nix build .#wac` and `nix build .#wasm-tools` succeed.
- [ ] `fixtures` regenerates every checked-in fixture byte-for-byte.
- [ ] The fixtures load, instantiate, and run under the harness on the native target.
- [ ] The corpus README lists each fixture, its WIT, and its build command.
