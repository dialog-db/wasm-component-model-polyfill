## What to build

Add a step to the smoke test in `rust/wcmp-smoke/src/lib.rs` showing a synchronous guest call whose result a host task computes inside the trampoline: a component export calls a host `async` function registered through the host-async registration entry; the host function's future reaches the host data through the accessor it is handed on each poll and resolves after the store's own turns poll it; with no suspend provider the nested-turn fallback runs the body and its lowering from inside the call; the guest returns the value. The evidence line names the input, the value the host task produced, that the export call was the only driver on the stack, and that no host task remained afterward. Use only the crate's public API: this step waits for the registration entry that PDD018 lists as a non-goal, and must not re-export `start_host_task`, `HostTask`, `LowerKind`, `SuspendSeam`, or `TableId`. The branch `sandbox-guest/card-d4b4f6-52fa1b75` (tip d92a8d8) holds a working version built on those re-exports, with a fake `TableId::fresh()` caller table, as a reference.
