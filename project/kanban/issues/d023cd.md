## What to build
Implement the third `canonopt` string encoding for host-side lift and lower, in memory and in flat slots: a length with the high bit clear is Latin-1 bytes, a length with the high bit set is UTF-16 code units. Lowering picks Latin-1 when every scalar fits in one byte and UTF-16 otherwise. Add round-trip tests through an export with `string-encoding=latin1+utf16`.

## Acceptance criteria
- [ ] A string lifted from a `latin1+utf16` export round-trips in both representations.
- [ ] The two `Latin-1+UTF-16 ... not yet implemented` lines in the expected-failures list are gone.
- [ ] The corpus `strings` directives that exercise the encoding pass.
