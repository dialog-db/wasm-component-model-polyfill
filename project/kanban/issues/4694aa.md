## What to build

Step 5 of the migration (add Wasmi). Host suspension in the Wasmi backend, filled with Wasmi's resumable calls.

A suspending host function returns a marker error. The resumable call is `call_resumable`, and the handle is `ResumableCallHostTrap`, which owns its own stack. The host resumes it with the host function's results. The backend declares `host_suspension` only after the shared host-suspension contract tests pass.

## Acceptance criteria
- [ ] A test starts three resumable calls in one store; each suspends in a suspending host function. The test resumes them third, first, second, and each finishes with its own results.
- [ ] A fourth call suspends with a host frame between its start and the suspension, and it traps.
- [ ] A test drops a store with waiting handles. Nothing panics.
- [ ] The Wasmi backend declares `host_suspension`.
- [ ] `lint` and `tests native debug` pass.
