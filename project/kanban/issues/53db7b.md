## What to build
The two review rounds of card `388338` accepted the list gate in `src/abi/lift.rs` (`lift_list`) and the alignment traps, and left findings that need one card. First, wording: the count gate at `lift.rs:242` reuses Wasmtime's "list pointer/length out of bounds of memory" for a list whose pointer and length are in bounds (a zero-size element list longer than the memory holds bytes); Wasmtime reports that shape as fuel exhaustion (`crates/wasmtime/src/runtime/component/values.rs:1015-1021`, `options.rs:524-541`) and `definitions.py:1347-1351` has no such gate, so the doc at `lift.rs:200-209` must say the message is borrowed, or the gate must adopt the reference's wording when the element-count bound lands. Second, the reference's first list trap is a constant cap `MAX_LIST_BYTE_LENGTH = (1 << 28) - 1` (`definitions.py:1337, 1348`), not a `checked_mul` overflow, so `list<u32>` with length `0x4000_0000` says "list length overflow" on wasm32 and "list pointer/length out of bounds of memory" natively; decide whether the polyfill adopts the constant cap (the spec's rule) and test the per-target answer either way. Third, a map lifted through `map_entries_type` (`lift.rs:46`, `flatten.rs:246`) reports "list pointer is not aligned" where Wasmtime says "map pointer is not aligned" (`values.rs:1062`). Fourth, the doc at `lift.rs:204-206` names zero-label flags and the empty record as zero-size shapes, but `definitions.py:1157-1162` requires `0 < n <= 32` labels and `:1190-1196` requires a record to have a field, so only a zero-length fixed list (`list<list<u32, 0>>`) is reachable from a real component; correct the doc and add a test for the reachable shape. Fifth, the missing tests: pointer size overflow at `trampoline.rs:1035` (unreachable on a 64-bit host), and the `None`-memory branch (`lift.rs:236, 254`) for an element type that reads no bytes. Sixth, pre-existing and adjacent: `AbiStrategy::size` (`src/abi/strategy.rs:157`) computes `current_pages as usize * 65536`, which wraps on a 32-bit host at 65536 pages.

## Acceptance criteria
- [ ] The count gate's doc says its wording is borrowed from Wasmtime's bounds trap, or the gate reports the reference's cause; either way a test pins the message for a zero-size element list that outnumbers the memory.
- [ ] The polyfill's first list trap is either the reference's constant cap or a stated departure, and a test pins the message for `list<u32>` of length `0x4000_0000` on both targets.
- [ ] A misaligned map pointer reports "map pointer is not aligned", proved by a test.
- [ ] The zero-size doc names only reachable shapes and `list<list<u32, 0>>` has a test on both targets.
- [ ] `AbiStrategy::size` does not wrap on a 32-bit host, proved by a unit test with 65536 pages.
- [ ] `lint` passes and `tests all` is green on both targets with the conformance summary unchanged.
