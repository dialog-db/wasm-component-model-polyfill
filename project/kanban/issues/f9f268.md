## What to build

Step 1 of the migration (build beside). Create `wcmp-wasm-core-web`, the browser backend of `wcmp-wasm-core`, over the WebAssembly JavaScript API. This card covers compilation, instantiation, externs, and capability probes, and runs the shared contract tests that apply in the web lane. Host function wrappers, memory access, trap kinds, and host suspension are later cards.

- **Compile and instantiate.** Asynchronous compile and instantiation through `WebAssembly.compile` and `WebAssembly.instantiate`, so a module above Chromium's 8 MB synchronous limit loads. A synchronous compile for small generated modules; above the limit it fails with a structured error. No module cache by bytes.
- **Boundary only.** Describe the imports and exports of a module and nothing else. A GC-typed global or tag inside a module is not a reason to refuse it; the engine decides.
- **Tags and references.** Tags are an extern kind (import, export, link, parameter types). `funcref`, `externref`, and `i31ref` are readable; GC objects, `exnref`, and continuations pass through opaque.
- **Linking.** Pass an exported function to another instance's import as the export's own function object, so a call between instances is WebAssembly to WebAssembly.
- **Probes.** Read each JSPI function and run a small probe per feature when the engine is made. A browser without a feature loads the backend and declares less.
- **No eval.** Never make a function from a string of source. JavaScript carries only what the WebAssembly JavaScript API alone can do.

## Acceptance criteria
- [ ] A module that defines a global of a GC reference type and exports a tag instantiates in Chromium, and the test calls an exported function.
- [ ] A module with an internal table of a concrete reference type, an internal tag, and an internal GC global, which exports one function, loads.
- [ ] A tag crosses the boundary between two instances: the host reads its parameter types, and a guest throws in one instance and catches in the other.
- [ ] A module above 8 MB compiles and instantiates asynchronously in Chromium in the web lane. A synchronous compile of it fails with a structured error.
- [ ] A test that forces a probe to fail shows the backend loading and declaring less.
- [ ] The backend source makes no function from a string (no `eval`, `new Function`, or equivalent).
- [ ] `lint` and `tests web debug` pass.
