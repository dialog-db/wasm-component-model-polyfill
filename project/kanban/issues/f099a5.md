## What to build

File the issue below on Zena (https://github.com/elematic/zena/issues). The
owner files it, since an agent takes no action on GitHub. Once Zena offers the
hook, the compiler component's `check` against a declared world (`analysisFor`
in `zena/compiler/compiler.zena`) passes the world's export wrapper again.

Found on 2026-10-13 during card f6445b, the port of the compiler entry to
Zena's per-compile options (`91c27df`). Before the port, the entry set
`componentWrapperSynth` on the `CompilerOptions` it gave both the compiler and
the language service, so `check` reported faults in a declared world's
exports. Now the wrapper writer is a field of `CompileOptions`, and
`LanguageService` builds its own `{entry, target}` for each compile with no way
to add it. So `check` against a declared world uses the compiler's default
wrapper and misses those faults. `compile` still reports them.

### Proposed issue text

> **Title:** Language service: let a caller pass per-compile options such as
> `componentWrapperSynth`
>
> Since `91c27df` ("Make the target a property of a compile, not of a
> compiler"), the component entry wrapper writer is a field of
> `CompileOptions`, which each compile receives. `LanguageService` (and
> `createLanguageService`) build their own `CompileOptions` from the entry and
> the target only (`packages/language-service/zena/lib/service.zena`, around lines
> 109-120 and 377 at `43234db`). An embedder that compiles against a declared
> WIT world gives `compile` a `componentWrapperSynth`, so the world's exports
> are checked. Through the language service the same source is checked
> against the default wrapper, and a fault in the world's exports goes
> unreported in the editor.
>
> `#compile` is private and `Compiler` is `final`, so the embedder cannot add
> the option itself.
>
> Suggested change: let `LanguageService` and `createLanguageService` take an
> optional `CompileOptions` template (or just `componentWrapperSynth`) that is
> merged into each compile's options, with the entry filled in per document.
