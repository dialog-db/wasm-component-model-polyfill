## What to build
The fixture built from the WASI 0.3 `wasi:http` handler world exists at `tests/corpus/fixtures/wasi-http/handler.wasm`, built by wit-bindgen, whose runtime links `task.cancel` in every `async` export and `subtask.cancel` in every awaited import. Its `handle` export takes a `request` whose body is a `stream<u8>` and whose trailers are a `future<result<option<trailers>, error-code>>`, and answers with a `response` that carries both; its `drain` export writes bytes into a `stream<u8>`, reads them back, and resolves a future beside them. Write a repository test that instantiates the fixture with a host `wasi:http/types@0.3.0` supplied through the linker and the host surface: the resources and functions the handler imports (`fields`, `request.new`, `request.consume-body`, `response.new`, and the resource drops), with the request body as a `StreamReader<u8>` over a producer and the trailers as a `FutureReader` over an `async` block. The test calls `handle`, pipes the response body to a consumer, reads the trailers future, and checks that both carry what the request carried; it calls `drain` and checks the bytes come back. The handler's cancellation paths are never reached. In the corpus harness the fixture's two `drain` directives (`fixtures/wasi-http.wast`) turn green only if the component's `wasi:http/types` import resolves; the harness registers no new host item, so record what a live run gives those lines and leave them outside the design's owned lines if they stay. The browser run proves the same test with a producer that awaits a JavaScript promise.

## Acceptance criteria
- [ ] The fixture instantiates with a host `wasi:http/types@0.3.0` and its `handle` export answers a request with a body stream and a trailers future, proved by a repository test on both targets.
- [ ] The fixture's `drain` export returns the bytes written through the guest's own stream and future, proved by the same test.
- [ ] The fixture's cancellation paths stay unreached, and the lines of `fixtures/wasi-http.wast` carry the reason a live run gives them.
- [ ] `lint` passes and `tests all` is green on both targets.
