## What to build

A browser test proves that the polyfill runs over the new browser backend under a strict content security policy. The test installs `script-src 'self' 'wasm-unsafe-eval'` and checks that the browser enforces it (for example, a probe `eval` is refused). Under the policy, it runs a composition that prepares a call, and it calls a host function of more than eight parameters.

The smoke app under `rust/wcmp-smoke/web` already has a policy check. Extend it or add a test beside it.

## Acceptance criteria
- [ ] The test installs `script-src 'self' 'wasm-unsafe-eval'` and shows the browser enforces it.
- [ ] Under the policy, a composition that prepares a call runs.
- [ ] Under the policy, a host function of more than eight parameters is called.
- [ ] The test runs in a menu lane that `tests all` includes.
