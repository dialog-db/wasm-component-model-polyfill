## What to build
The review of card `91b9aa` accepted the poll none path and left findings that need one card. First, an event pointer that leaves the memory surfaces as `Error::internal` ("polyfill internal invariant violated: guest memory access failed: …"): `write_payloads` calls `BoundaryContext::write_own_bytes` (`src/abi/context.rs:309-319`), `strategy.store` answers `AbiCause::SubstrateFailure` (`src/abi/strategy.rs:86-89`), and `unlabelled` (`context.rs:371-376`) maps it to `Error::internal`, whose doc (`src/error.rs:154-158`) says reaching it is a polyfill bug. A guest-supplied pointer past the end of memory is not a polyfill bug; per the sibling gate `misaligned_event_pointer()` (`src/executor/waitable_builtins.rs:456-464`) it should be `AbiError { position: AbiPosition::Argument(1), valtype: U32, cause: AbiCause::OutOfBoundsMemory { offset: pointer, length: 8 } }`. The same path serves `waitable-set.wait`, and the new test `it_traps_a_poll_of_an_empty_set_on_every_pointer_a_wait_traps_on` now pins the Internal wording for the 65532 case; change the cause and the test together. Second, with both arms converging, `HandleTables::poll_waitable_set` (`src/resource/tables.rs:324-329`) already answers `Event::none()` for an empty set, so the `set_has_pending_event` pre-check and the `Option` at `waitable_builtins.rs:289-297, 307` are dead weight; reduce the block to one `poll_waitable_set` call (`set_at` still validates the handle). Third, nothing pins that a pointer whose eight-byte pair straddles the end writes nothing (the polyfill follows Wasmtime's check-the-pair-first rule, not the reference's write-p1-then-trap); after the 65532 trap, a peek at 65532 should still read the guest's poked value.

## Acceptance criteria
- [ ] An event pointer that leaves the memory fails `waitable-set.wait` and `waitable-set.poll` with the out-of-bounds ABI cause naming the pointer and the eight-byte length, proved on both targets; no test pins the Internal wording any more.
- [ ] The poll none path is one `poll_waitable_set` call with the same behaviour, and the doc states that the set answers the none event itself.
- [ ] A test pins that a straddling pointer writes nothing, and the doc names the Wasmtime rule the polyfill follows over the reference's partial write.
- [ ] `lint` passes and `tests all` is green on both targets with the conformance summary unchanged.
