## What to build

In Wasmtime 50, a `call_async` future that the host drops while the call is
queued makes the call trap when it starts, and the store is poisoned
(`4d23d6221`). Wasmtime's own TODO calls this a stopgap. The polyfill runs the
queued call, because the call owns its parameters
(`instance/func.rs:1014-1030`). The owner chose to keep this behavior.
