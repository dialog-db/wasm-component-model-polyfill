## What to build
Close the non-blocking findings the review of card 4e6441 left open.

1. **A failed host-task abort must not quietly drop completed calls.** In `poll_host_tasks` (`src/store/store_context.rs:1169-1171` with `:1210-1214` at the landing), if `abort_host_task` fails, the turn drops the calls that had already completed without poisoning the store; the comment at `:1210` assumes the store is poisoned. It is reachable only on an internal invariant break (a poisoned lock, a missing subtask record). Poison or keep the completed calls, and make the comment true.
2. **A second cancel of a host callee after `BLOCKED`.** It traps with the polyfill's own "`subtask.cancel` called twice for the same subtask" (`src/executor/cancel.rs:279`); for a host task Wasmtime traps "`subtask.cancel` called after terminal status delivered" (`CalleeDone { cancelled: true }`). Decide which message a host callee gets, following PDD023, and test it.
3. **Missing tests** on both targets: a future that completed but whose lowering is still queued when the cancel marks it (the mark finds nothing); a task marked while it is out for a poll; the abort failure path from item 1; the host-task call count after an abort; a future whose `Drop` poisons the store.
