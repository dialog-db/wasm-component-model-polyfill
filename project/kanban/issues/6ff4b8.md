## What to build
Replace the `Error::Unsupported("locally-defined resources")` arm for `GlobalInitializer::Resource` with a plan entry that carries the resource's defining component instance and its destructor source (a `CoreDef` projected through `lift_core_def`, or none). Resolve the resource trampolines (`resource.new`, `resource.rep`, `resource.drop`) for a local resource against that entry instead of a host registration. Mint a fresh resource type identity per instantiation.

## Acceptance criteria
- [ ] A component that declares `(type (resource (rep i32) (dtor (core func $f))))` translates and instantiates.
- [ ] Two instantiations of one component carry distinct resource type identities.
- [ ] The corpus files that were rejected for locally-defined resources now reach their directives.
