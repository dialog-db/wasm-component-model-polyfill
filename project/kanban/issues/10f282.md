## What to build

Step 1 of the migration (build beside). Trap kinds in the browser backend.

The browser gives a trap as an error object with a message that each engine words its own way, and no trap code. The browser backend maps the messages of V8, SpiderMonkey, and JavaScriptCore to a `TrapKind` with a table. A message that is not in the table becomes `Other` with the engine's message; it never becomes a wrong kind. Each kind carries Wasmtime's message, so a report reads the same from every browser. A host error is `Host(error)` through the wrappers. An exception that reaches the host uncaught is `UncaughtException`, with the `exnref` opaque and the message `thrown Wasm exception`.

Cite the source of each engine's messages in the table.

## Acceptance criteria
- [ ] The shared trap fixture runs in the web lane, and each kind and message matches the Wasmtime backend's.
- [ ] A message that the table does not know becomes `Other` with the engine's message.
- [ ] A guest throws an exception that nothing catches. The call fails with `UncaughtException` and the message `thrown Wasm exception`.
- [ ] The table covers V8, SpiderMonkey, and JavaScriptCore, with a citation for each engine's messages.
- [ ] `lint` and `tests web debug` pass.
