## What to build

PDD026, "The Compiler Component". Build Zena's compiler as a component from the pinned toolchain, plus the source bundle that its `read-source` import serves.

- **Entry module.** A small Zena module in this repository calls the compiler's own library code, as `packages/zena-compiler/zena/cli/api.zena` does, and exports `compile` through the `compiler` world in PDD026. It gives the WIT parser a reader that calls `read-source`, so the parser never touches a file system. Use the fork's reader change. Keep the module in one place that both the Zena compatibility suite and the demo build from.
- **The export is `async func`.** A synchronous export with a `list` or `result` return fails to build on the component target.
- **Build.** A Nix derivation compiles the entry module with `zena build --target component` against Zena's source tree at the pin, and validates the result with `wasm-tools validate`.
- **Toolchain source bundle.** A Nix derivation packs every file a compile can read through `read-source`: Zena's standard library and the WASI WIT that Zena vendors, keyed by the path the compiler asks for. The demo later adds its own WIT and authoring library to it. Pick one format that a native test host and a browser context can both read.

The spike of 2026-10-01 built this at 2,291,982 bytes, importing only the host interface, `wasi:cli@0.3.0`, and `wasi:clocks@0.3.0`. One small compile reads about 50 distinct files.

## Acceptance criteria
- [ ] The compiler component builds from the pinned toolchain. The build compiles the entry module with Zena's `--target component`.
- [ ] The result validates with `wasm-tools`, and it imports no `wasi_snapshot_preview1` function and no `wasi:filesystem` interface.
- [ ] Its imports are exactly the host `read-source` interface, `wasi:cli/stdout@0.3.0`, `wasi:cli/stderr@0.3.0`, and `wasi:clocks/monotonic-clock@0.3.0`. Its one export is `compile` with the signature in PDD026.
- [ ] The source bundle holds every file that a compile of a small program reads. A test compiles one under Wasmtime with `read-source` served only from the bundle, and the bytes equal `zena build` of the same source.
- [ ] `tests all` and `lint` pass.
