## What to build

Wasmtime 50 makes the host task current while its future is polled
(`3c1b0bfa2`). Before, a host import whose future called back into wasm with
a borrowed resource left the borrow counted, and the guest's later
`resource.drop` trapped. Wasmtime's test is `host_call_cleans_up_borrow`
(`tests/all/component_model/resources.rs`). Nobody has checked the polyfill.

## Acceptance criteria

- [x] A port of `host_call_cleans_up_borrow` passes on both targets, or the
      polyfill is fixed so that it does.
