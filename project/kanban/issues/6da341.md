## What to build
`tests/conformance.rs` (around lines 274-290) passes an `assert_invalid` or `assert_malformed` directive on any `Err(_)` from `Component::new` without reading the message, so a component rejected for the wrong reason counts as a pass and only a binary that parses when it should not reaches the `validation` category. Wasmtime's wast runner matches the message. Apply the rule `assert_trap` already uses, `err.contains(message)`, to both directives; the directives that then fail are recorded as `validation` with their live reason, which is what the regeneration verb exists for, so this card waits for it. Lines for files the reference itself fails keep the parenthetical the existing `validation` lines carry, "(the reference implementation does not pass this file either, see cm/nyi.txt)".
