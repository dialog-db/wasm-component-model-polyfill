## What to build

Follow-up from the second review of the PDD027 series. A generic derived type compiles whatever its type parameters are called.

- **Today:** the methods that the derive macros and `flags!` generate declare their own host-data parameter as `<D: 'static>` (`rust/wcmp-macros/src/component.rs`, each `lower_flat`, `lower_memory`, `lift_flat`, and `lift_memory`; `rust/wcmp-macros/src/flags.rs` likewise).
- **Failure:** a generic record such as `struct Pair<D> { a: D, b: D }` inside `impl<D> ... for Pair<D>` fails with E0403, because `D` is declared twice.
- **Wasmtime:** has the same flaw with `T`.
- **Coverage:** no test derives a generic type.

Name the method parameter something a user's type cannot use, such as `__WcmpD`, in both macros.

## Acceptance criteria
- [ ] A generic derived record and a generic derived variant, each with a type parameter named `D`, compile and cross both ways through a guest on both targets.
- [ ] `lint` passes, and `tests all` is green on both targets with the conformance summary unchanged.
