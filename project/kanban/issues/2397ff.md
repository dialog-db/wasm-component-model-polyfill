## What to build

Move the workspace from Wasmtime `=49.0.0-rc.1` to the 50.0.0 release.
Wasmtime 50 needs rustc 1.97, so the Rust toolchain moves too. The
wasm-tools crates move from 0.258 to 0.261, the version that Wasmtime 50
links. The spec test suite pin moves to the commit that Wasmtime 50 pins.

The published `wcmp` asks for `wasmtime-environ` with a caret requirement.
A consumer that also uses `wasmtime` 50.0.x then resolves to one
`wasmtime-environ`.

## Acceptance criteria

- [ ] `wasmtime`, `wasmtime-environ`, and `wasmtime-wasi` resolve to 50.0.0,
      with caret requirements.
- [ ] `wasmparser`, `wasm-encoder`, and `wit-parser` keep one version each
      in the graph.
- [ ] The toolchain is rustc 1.97 or later.
- [ ] Prose that names the pinned Wasmtime version names 50.
- [ ] `downstream lock` refreshes the lock of the downstream consumer.
- [ ] `lint` and `tests all` pass.
