## What to build

Move the workspace from Wasmtime `=49.0.0-rc.1` to the 50.0.0 release.
Wasmtime 50 needs rustc 1.97, so the Rust toolchain moves too. The
wasm-tools crates move from 0.258 to 0.261, the version that Wasmtime 50
links. The spec test suite pin moves to the commit that Wasmtime 50 pins.

The published `wcmp` asks for `wasmtime-environ` with a caret requirement.
A consumer that also uses `wasmtime` 50.0.x then resolves to one
`wasmtime-environ`.

The bump does not build or pass alone. It lands in one series with
90d64c, 0137e0, 643072,
48b439, and 4b26f4. This card also carries the small
fixes that the bump needs:

- `wcmp-wasm-core-web` reads `SubType::supertype_idxs`, which replaces
  `supertype_idx` (`type_registry.rs:129`).
- The trap test of `wcmp-wasm-core-wasmtime` lists the four new Wasmtime trap
  kinds (`errors.rs:149`).
- The `wasmtime-version` check reads the locked version and accepts one
  Wasmtime, one `wasmtime-wasi`, and one `wasmtime-environ`.
