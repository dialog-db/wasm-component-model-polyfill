## What to build
Build the five thread built-ins that suspend or switch, behind the gate `wasm_component_model_threading`. No provider exists yet, so they run on the nested turn.

| Built-in | What it does |
| --- | --- |
| `thread.suspend` | Suspends the current thread until another thread resumes it. |
| `thread.suspend-then-resume` | Suspends the current thread and switches to a suspended thread. |
| `thread.yield-then-resume` | Makes the current thread ready and switches to a suspended thread. |
| `thread.suspend-then-promote` | Switches to another thread if it is ready, and otherwise suspends the current thread. |
| `thread.yield-then-promote` | Switches to another thread if it is ready, and otherwise yields. |

Each first traps with the cannot-leave cause when the may-leave flag is clear. A switch is a suspension that names the thread to run next. The frame that resumed the current thread runs the named thread before anything else, which is the reference's `Thread.resume` loop. The switch slot of PDD018 holds that thread when the frame is a turn of the scheduler. A switch or a resume that names a thread which is not suspended fails with "cannot resume thread which is not suspended". A promote that names the current thread traps, as the reference states. Each blocks through the try and finish parts of the seam.

Without a provider:
- A suspension waits until a nested turn runs the work that resumes the thread.
- A switch to a thread that never ran starts that thread as a nested start on the real stack, above the trampoline, marked on the store's scope stack.
- A switch to a thread that is suspended below the current frame cannot run, and fails with the stack-switch cause.

## Acceptance criteria
- [ ] Each of the five built-ins has a repository test of its behavior on the nested turn, on both targets.
- [ ] A switch to a thread that never ran starts it as a nested start, and a switch to a thread suspended below the current frame fails with the stack-switch cause, each proved by a test.
- [ ] A promote that names the current thread traps, and a switch to a thread that is not suspended fails with Wasmtime's message, each proved by a test.
- [ ] Each thread directive of the corpus either passes or carries its true cause from a live run.
- [ ] `lint` passes and `tests all` is green on both targets, any directive that starts passing has its line removed from the expected-failure list, and every line whose reason this card changes is refreshed from a live run.
