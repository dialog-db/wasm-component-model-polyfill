## What to build
Per call: `Func::call` clones the export's signature and canon options into the task record (`src/instance/func.rs:187`) and again into the item (`:569-578`), and deep-copies every argument before lowering (`:200`); `func_for` deep-clones `FunctionType` and `CanonOptions` on every export lookup after a linear scan of the exports (`src/instance/instance.rs:124-129, 164-173`); the host-import trampoline clones the instance's resource-table vector three times and takes two mutexes four to six times per call (`src/executor/trampoline.rs:595-598`, `src/abi/instance.rs:25`), and `lift_spilled_arguments` recomputes the spill layout per call (`trampoline.rs:1007-1010`). Per instantiation and compile: every instantiation sweeps and sorts every host resource label in the linker even for a component that imports no resource (`src/executor/instantiate.rs:166-168, 715-737`); `Component::new` awaits each core module's `WebAssembly.compile` in sequence in the browser (`src/executor/translate.rs:100-101`) and parses each module three times, in the translator, the runtime layer, and `read_shape` (`src/module/module.rs:53-54`). Put the immutable parts behind `Arc` on `Func`, the task record, and the lowering spec; cache the spill layout with the signature; sweep labels once per linker or not at all for a component without resource imports; issue the compiles together. An `InstancePre` for a host that instantiates one component many times is a larger step; note what it would need rather than build it. Measure with the benchmark suite and record the numbers on this card.

## Acceptance criteria
- [ ] A call clones neither the signature nor the options nor the resource-table vector, and the spill layout is computed once per function, proved by tests or by a traced note per site.
- [ ] An instantiation of a component that imports no resource performs no label sweep, and the browser issues its core-module compiles together.
- [ ] The call-floor and `Component::new` benchmarks show the before and after numbers on both targets, recorded on this card.
- [ ] `lint` passes and `tests all` is green on both targets with the conformance summary unchanged.
