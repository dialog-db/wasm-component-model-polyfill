## What to build
`src/backend.rs` describes the browser's refusal of a re-entrant host call as reaching "the very import the block is inside" and calls it the one shape of component that fails only in the browser. It is broader: a nested turn also refuses any task that calls a host function already on the stack, including the blocking built-in's own trampoline, so two tasks of one instance both blocking in `waitable-set.wait`, or two synchronous lowers of the same host `async` import, fail in the browser and succeed natively. Card `0a7c63` makes the cause reach the host; this card states the rule where a reader looks for it: the module doc of `backend.rs`, the target paragraph of `tests/corpus/README.md`, and the Target Differences section of PDD020, in the form "without a suspend provider, a nested turn cannot enter any host function already on the stack".

## Acceptance criteria
- [ ] The three documents state the rule, and PDD020 is formatted with `markdown format`.
- [ ] A web test pins one shape (two tasks of one instance blocking in the same built-in) as refused with `SchedulerCause::ReentrantHostCall`, and the same component passes natively.
- [ ] `lint` passes and `tests all` is green on both targets with the conformance summary unchanged.
