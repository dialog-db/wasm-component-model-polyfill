## What to build

PDD026, "The Two Contexts: Build". Make the demo's crate and the menu command that serves it. No components yet.

- **Crate.** One new crate in this workspace (`publish = false`), inheriting its dependencies from `[workspace.dependencies]`. Trunk builds one binary for the page and one for the service worker (`data-type="worker"`).
- **Service worker entry.** A small JavaScript entry. During its first evaluation it adds the `fetch` and `message` listeners and starts the Rust module without top-level `await` and without a dynamic `import()`. Each event waits until the start completes, then calls into the Rust module. A request the Rust side does not claim goes to the network.
- **Registration.** The page registers the service worker itself, because Trunk does not. The service worker calls `skipWaiting` and `clients.claim`.
- **Menu.** A menu command builds the demo through a Nix derivation and serves it on a local port. Add it to the menu text.
- **Lint.** The crate passes the existing lint checks, `clippy-wasm32` included.

## Acceptance criteria
- [ ] The menu serves the demo. A menu command builds the demo and serves it on a local port.
- [ ] The page loads, and the service worker controls it after one reload at most.
- [ ] A static file of the demo loads through the service worker from the network.
- [ ] `tests all` and `lint` pass.
