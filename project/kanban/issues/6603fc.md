## What to build
Every `tests native|web <profile>` lane and `tests all` already pass their extra arguments to `cargo nextest run` (`menuTestCommand` in `flake.nix` ends its command with `"$@"`, and `tests all` forwards `"$@"` to each lane), so `tests native debug -E 'test(it_renders_the_task_causes)'` runs one test in seconds. Nothing says so: an implementor working card `e4cb68` reported that verifying two new unit tests cost a full two-target run of the whole suite because "`tests` has no test-name filter". Make the forwarding visible where an agent looks: the `description` of the `tests` command and of each lane in `flake.nix` names the pass-through with a `-E 'test(<name>)'` example, and `project/kanban/.dispatch-instructions.md` says the same in its environment section. Do not add a new menu command; the feature exists.

## Acceptance criteria
- [ ] `nix develop -c menu` shows, on the `tests` command or its lanes, that extra arguments go to `cargo nextest run`, with a filter example.
- [ ] `project/kanban/.dispatch-instructions.md` tells an implementor how to run one test through the menu.
- [ ] `lint` passes.
