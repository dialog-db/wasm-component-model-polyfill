## What to build

The polyfill traps on a same-instance adapter only because Wasmtime 50's
adapter compiler does. Wasmtime plans to reconcile the trap with the spec. When
a Wasmtime release removes it, the polyfill moves to that release and restores
the spec behavior.

## Acceptance criteria

- [ ] A Wasmtime release without the trap is found, or this card records the
      latest release that still has it.
- [ ] If the trap is gone, a card moves the polyfill to that release and
      restores the test that expects the call to succeed.
