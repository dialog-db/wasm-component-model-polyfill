## What to build
The design every concurrency feature joins: the pieces of the Component Model's async model that are shared by tasks, subtasks, waitables, streams, and futures, settled once. The translator already parses every concurrency built-in (`wasmtime-environ` emits trampolines for task, waitable-set, stream, future, error-context, context, backpressure, and thread built-ins, and the prepare-and-start call protocol); the polyfill rejects them at one seam in `src/executor/translate.rs`. So this PDD designs runtime, not parsing.

The PDD must settle:

- **The scheduler.** One cooperative scheduler per `Store`, runtime-agnostic: the host's `Func::call` future polls it, and a waker is the only thing it needs from the host's executor. How it runs on native under any executor and in the browser under `wasm-bindgen-futures` with the same code. The invariant that guest code runs only while a host future is being polled.
- **Tasks.** The task record, its states per the spec, the per-instance task and waitable tables (the same shared handle table as resources, per the canonical ABI's runtime-state rules), and how a task relates to the call scope the borrow tracking already keeps.
- **Waitables and events.** The waitable kinds, event codes, and how readiness is recorded and delivered, with the spec's ordering rules.
- **Host and guest interleaving.** How a host future and a guest task share the one event loop; what a host `async` function is on the public API and from which lowered form it may be called; how backpressure and instance flags gate entry.
- **The stackless and stackful forms.** That the callback form needs no stack switch on either target, that the stackful form does, and that the model must let the stackful form be added without changing the callback path.
- **The lift and lower seam.** Where the eager ABI's assumptions (`cabi_realloc`, direct memory writes) are allowed to live, so that stream and future payloads do not spread them and a lazy ABI can later sit beside the eager one, as the compatibility outlook intends.
- **Corpus.** The async directories of both suites are vendored with every directive listed as `deferred-feature`, so each later feature shows progress by flipping lines. Name the vendoring as a prerequisite of the first implementation card.
