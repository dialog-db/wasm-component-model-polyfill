## What to build
Generate Wasmtime's `LinkOptions` for `@unstable` WIT items (`crates/wit-bindgen/src/lib.rs:3589-3718` at `v49.0.0-rc.1`): one boolean setter per feature, `From` conversions between world and interface options, and an `options: &LinkOptions` parameter on `add_to_linker` when any gated item is present. A gated item is registered only when its feature is on.

PDD028 generates every gated item as if each feature were on, which is PDD003's "tolerate" target. This card makes the gates switchable at link time, as Wasmtime does, and removes a difference between the Wasmtime and polyfill glue modules.

## Acceptance criteria
- [ ] The macro emits `LinkOptions` with Wasmtime's shape for a WIT with `@unstable` items, and `add_to_linker` honours it.
- [ ] The codegen corpus entry `unstable-features.wit` generates the same API as Wasmtime's macro and runs with each feature on and off, on both targets.
- [ ] PDD003's feature-gate row and PDD028's ledger are updated.
- [ ] `lint` passes and `tests all` is green.
