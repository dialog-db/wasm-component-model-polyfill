## What to build

A note under `notes/` that tells a host author how to use `wcmp::bindgen!`.
It covers the invocation forms, the options, imports and exports, resources,
async functions, and the two targets. It lists each difference from
Wasmtime's `bindgen!`, with the reason.

## Acceptance criteria

- [ ] The note exists and the README and `notes/feature-support.md` link to
      it.
- [ ] Every difference from Wasmtime that the note lists agrees with the
      option ledger of `wcmp-bindgen`.
- [ ] `markdown` passes.
