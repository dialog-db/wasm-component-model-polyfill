## What to build

Step 4 of the migration (retire). Prove that the runtime layer and the polyfill build as dependencies of an outside crate with no `[patch]` section.

Add a check with a crate outside the workspace that depends on the polyfill and on one backend by path (as a crates.io consumer would by version), with no `[patch]` section, and builds for native and `wasm32`. Add a check that `cargo package` succeeds for each runtime layer crate and for the polyfill. This card does not publish anything.

A release candidate of Wasmtime can stay in the tree; it blocks a release, not this check.

## Acceptance criteria
- [ ] A crate outside the workspace, with no `[patch]` section, depends on the polyfill and one backend and builds for native and `wasm32`.
- [ ] `cargo package` succeeds for `wcmp-wasm-core`, `wcmp-wasm-core-web`, `wcmp-wasm-core-wasmtime`, and the polyfill.
- [ ] Both checks run as flake checks, and `lint` or `tests all` runs them.
