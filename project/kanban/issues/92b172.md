## What to build

PDD026, "HTTP on Both Ends".

- The page's host framework implements `wasi:http/client@0.3.0` `send` with `fetch`, through the shared `wasi:http/types` subset, and links it into every element.
- `zena:fetch` sends only `GET`. The `demo:element` authoring library adds a client that sends any method, with headers and a body, and reads the status, headers, and body of the response.

## Acceptance criteria
- [ ] An element sends `GET`, `POST`, `PATCH`, and `DELETE` with headers and a JSON body to a route. The route sees each method, header, and body, and the element reads the route's status, headers, and body.
- [ ] Each of those requests leaves the element as a `wasi:http` request, goes through `fetch`, and reaches the route component through the service worker. The response carries the `x-demo-route` header.
- [ ] `tests all` and `lint` pass.
