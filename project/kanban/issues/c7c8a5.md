## What to build
`check_items` in `src/linker/resolve.rs` (around lines 369-375) returns `Ok(())` early for an import whose type is an interface but whose extern kind is not an instance, so an import written as `(import "pkg:ns/iface@0.1.0" (func async ...))` reaches neither the signature comparison nor the registration-kind check, and the module doc at `resolve.rs:27-32` states the link rule without that caveat. Decide from the Component Model's import rules whether such an import is a function import under an interface name (then route it through `check_function_item`) or an invalid shape (then fail with a structured `LinkError`), implement that, and make the module doc true.

## Acceptance criteria
- [ ] A function import under an interface name is either type-checked and kind-checked like a root import or refused with a structured error, proved by a test for each mismatch the rule covers.
- [ ] The module doc on `resolve.rs` states the rule as the code enforces it.
- [ ] `lint` passes and `tests all` is green on both targets with the conformance summary unchanged.
