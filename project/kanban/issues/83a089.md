## What to build
The second feature: `canon lower async`, so a guest calls a host function or another component's export without blocking. Design the prepare-and-start call protocol the translator emits (`PrepareCall`, `SyncStartCall`, `AsyncStartCall`), the subtask state machine and its events, `subtask.drop` and `subtask.cancel`, delivery of a return through the caller's waitable set, and the reentrance rules with the instance flags. Cross-component async calls come with it, because the fused adapters use the same intrinsics.

This is where the public API gains an asynchronous host function: state its shape on `LinkerInstance` (mirroring Wasmtime's names where one exists), how it reaches store data without holding the store across an await, and the rule that on a target without a stack switch it is callable only from an async-lowered import, with the error a synchronous caller gets.

Test Cases: a guest awaiting a host future; a guest calling a sibling component's async export; a sync export called from an async task and the reverse; subtask cancellation and drop; reentrance traps. Name the corpus files this phase owns (for example `async-calls-sync.wast`, `cross-abi-calls.wast`, `sync-barges-in.wast`, `cancel-subtask.wast`, `drop-subtask.wast`, `reentrance.wast`, the `during-sync-call-*.wast` group) and any that stay deferred with the reason.
