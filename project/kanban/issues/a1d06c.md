## What to build

PDD026, "Routes": "What an Author Writes", "What the Helper Does", "Lazy Compilation", and "Failure".

- **Authoring library.** The `demo:route` Zena module: a simple request (method, path parameters, query parameters, headers, body as text with a JSON reader) and a simple response (status, headers, body), with `json`, `status`, and `problem` (`not-found` to 404, `empty-title` to 422). The author exports one `handle` function.
- **Route world.** The `route-component` world from PDD026, in the demo's source bundle.
- **Glue.** It exports `wasi:http/handler@0.3.0`. Its `handle` reads the `wasi:http` request into a simple request, extracts the path parameters from the pattern (which it holds as a literal), calls the author's `handle`, writes the simple response back, and adds an `x-demo-route` header that names the pattern.
- **Helper.** `define_route(pattern, source)` records the route. The service worker matches each request against the patterns in the order of definition. A request that matches no pattern goes to the network.
- **Lazy compiles.** The service worker compiles a route on the first matching request after it starts, links the todo model and the `wasi:http` subset, and keeps the instance until the browser stops the worker.
- **Failure.** A route that fails to compile answers 500 with the diagnostics in the body. A route that traps answers that request with 500 and drops the instance. The next request compiles it again.

## Acceptance criteria
- [ ] A route defined with a pattern and Zena source answers a matching `fetch` from the page, with the `x-demo-route` header and its path parameters.
- [ ] An unmatched request goes to the network. A test fetches a static file of the demo. The response has no `x-demo-route` header.
- [ ] A route compiles again after the service worker stops. A test stops the service worker and sends a request. The response is correct.
- [ ] A route that traps answers 500, and the next request compiles the route again and answers correctly when the trap does not recur.
- [ ] A route that fails to compile answers 500 with the diagnostics.
- [ ] `tests all` and `lint` pass.
