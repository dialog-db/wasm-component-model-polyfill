## What to build
`lower_handle` (`src/abi/lower.rs:344-357`) lowers a `borrow<T>` parameter from `handle.rep` directly: it neither looks the handle up in the host's table for the resource type nor lends the host's owning entry for the length of the call. `ResourceHandle` is `Copy` with public fields, so a stale copy after `Store::resource_drop`, or a forged one, passes, and the guest receives a borrow of a freed or arbitrary rep. Because the host entry's lend count stays zero, `Store::resource_drop` from a re-entrant host function succeeds while the guest still holds the borrow (`remove_own` at `src/resource/tables.rs:612-631` refuses only a lent entry). Wasmtime does the same through its host table: a `Resource<T>` lowered as a borrow is first moved into the host table "to participate in state related to borrow tracking", a borrow is lifted out of that entry with the entry placed on the call's lender list, and only then is the guest's borrow entry inserted (`crates/wasmtime/src/runtime/component/resources/host.rs`, `lower_to_index`, the `Borrow` arm); taking the entry back out for a drop or an `own` lowering fails while the lend is out, which is the guarantee its `Resource<T>` docs state: an owned handle can be destroyed only while it is not actively borrowed. PDD014 lists `lower_borrow` as only incrementing the task's borrow count (around lines 51-53), so the design needs the lend line too; add it to the lend rule the guest-to-guest lend card settles. Look the handle up, refuse a missing or already-borrowed entry with the invalid-handle cause, and `lend_to` the crossing's scope, released when the scope ends as a guest lend is.

## Owner decisions (2026-09-21)
Lend it, as Wasmtime does. The polyfill's host table already holds every host handle from `Store::resource_new`, which is the state Wasmtime's resource enters on its first borrow, so the lend count on that entry is the same mechanism and this card is parity, not a departure.

## Acceptance criteria
- [ ] Lowering a `Val::Borrow` whose handle was released, or one the host never minted, fails with the invalid-handle cause on both targets.
- [ ] A host function called by the export that received the borrow cannot `resource_drop` the owning handle until the call ends, proved by a test that drops during and after the call.
- [ ] PDD014 or the lend rule's document states that a host lend is counted; `markdown format` has run.
- [ ] `lint` passes and `tests all` is green on both targets with the conformance summary unchanged.
