## What to build
Replace the compatibility table that `tests zena` prints with the compatibility report that PDD024's Reporting section describes: a list with one entry per scenario, one line per subject beneath it, and the reason beside each stage that comes before `pass`.

```text
zena at b2237f7

- async-sleep
  - Browser: parse (<error text>)
  - Native: parse (<error text>)
  - Wasmtime: pass
- scalar-export
  - Browser: pass
  - Native: pass
  - Wasmtime: pass

Passes: Browser 1/2, Native 1/2, Wasmtime 2/2
```

- The report is built from this run's observations, the browser included, not from the record. The run already holds each subject's reason, the error text of the step that stopped it; today `wcmp_scenario::Table` (`rust/wcmp-scenario/src/table.rs`) keeps only the stage.
- Subjects appear in the order `Browser`, `Native`, `Wasmtime`. A line whose stage is `pass` holds only the stage. A line whose stage comes before `pass` holds the stage and the full reason text in parentheses, as the run observed it, without truncation. Stage names are the record's (`pass`, `parse`, ...).
- A header line names the pin. A footer counts the passes of each subject.
- Print the report after a gate failure too, after the differences `tests zena` already prints.
- The README copy of the report belongs to card 0ea332; this card changes only the command's output and the type behind it.
- A first attempt against an earlier version of this card, which kept the table and added a details block after it, is delivered to your mirror as `origin/delivered/card-95a419-4f744dc7` (`823e7f83c`, new `rust/wcmp-scenario/src/details.rs`; run `git fetch origin` to see it). Reuse what fits; it is not a base to build on.

## Acceptance criteria
- [ ] `tests zena` prints the report: the pin, one entry per scenario with a line per subject in the order `Browser`, `Native`, `Wasmtime`, the reason beside each stage before `pass`, and a footer of pass counts per subject.

- [ ] A unit test fails when a reason is dropped, a stopped subject is left out, or the subject order changes, and it runs on both targets.
