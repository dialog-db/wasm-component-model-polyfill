## What to build

PDD027, "The Typed Handle" and "The Dynamic Handle". Replace `ResourceHandle` with Wasmtime's three handle types, each implementing the typed value traits (Wasmtime `resources/host.rs`, `host_static.rs`, `host_dynamic.rs`, `any.rs` at `v49.0.0-rc.1`).

- **`Resource<T>`.** A typed handle to a host resource of identity `ResourceType::host::<T>()`. `T` is a marker, so it is `Send + Sync` for every `T`. Not `Clone`. Wasmtime's four states (`host.rs:37-60`): a borrow, owned in no table, owned and moved into a guest, owned and in the host table. A second lowering as `own` fails with "host resource already consumed". The first lowering as `borrow` puts it in the host table so the borrow is tracked. Methods: `new_own`, `new_borrow`, `rep`, `owned`, `try_from_resource_any`, `try_into_resource_any`. Its type check accepts `own` or `borrow` of identity `host::<T>()` and never a guest resource.
- **`ResourceDynamic`.** The same handle for a `host_dynamic` type, carrying the `u32` of its type: `new_own(rep, ty)`, `new_borrow`, `rep`, `ty`, `owned`, `try_from_resource_any`, `try_into_resource_any`. Its type check accepts any `host_dynamic` type, and its lowering compares the `u32`.
- **`ResourceAny`.** The dynamic handle, replacing `ResourceHandle`. It holds a host-table index, the identity, and whether it is owned. It keeps today's generation and rep checks (the `Stale` and `RepMismatch` refusals). Methods: `ty`, `owned`, `resource_drop(store)`, `try_from_resource`, `try_into_resource`. Its type check accepts any `own` or `borrow`. Its lowering compares the identity and fails with the ABI error for a handle of the wrong resource type.
- **`Val`.** `Val::Own` and `Val::Borrow` become `Val::Resource(ResourceAny)`, with own or borrow read from `owned()`.
- **Removal.** `ResourceHandle`, `Store::resource_new`, `StoreContext::resource_new`, `HostCall::resource_new`, and `Store::resource_drop`. Move every caller (baseline tests, conformance, smoke, demo, Zena host) to the new handles.

## Acceptance criteria
- [ ] A resource crosses as `Resource<T>` on both targets. The host makes a handle with `Resource::new_own` and passes it to a guest as an `own`. A host function then receives the guest's `borrow` of it. The rep matches at each step. A second lowering of the same owned handle as an `own` fails with "host resource already consumed".
- [ ] A resource crosses as `ResourceDynamic`. The host registers `host_dynamic(1)` and `host_dynamic(2)`, and passes a handle of each to a guest and back. The rep and type match at each step. A handle of type 1 fails to lower where the component declares type 2.
- [ ] A resource crosses as `ResourceAny`. The host receives an owned guest resource as `ResourceAny` and passes it back. It receives a second one and releases it with `resource_drop`, and that destructor runs once. A `ResourceAny` of the wrong type fails when lowered. `try_into_resource` succeeds for the right `T` and fails for another.
- [ ] A type check compares resources by identity. Two interfaces each declare a resource named `error`, registered with `host::<A>()` and `host::<B>()`. A typed host function taking `Resource<A>` links to a function of the first and fails to link to a function of the second.
- [ ] The host table refuses a stale handle: a `ResourceAny` whose slot was freed and used again fails with "host-owned resource was already de-allocated".
- [ ] A resource type has one identity in every interface. With `host::<T>()` registered under interfaces A and B, a function of A returns an `own` to the host, the host passes it to a function of B, and the rep matches.
- [ ] `ResourceHandle`, `Val::Own`, `Val::Borrow`, and every `resource_new` no longer appear in `public-api.txt`.
- [ ] `lint` passes, and `tests all` is green on both targets with the conformance summary unchanged.
