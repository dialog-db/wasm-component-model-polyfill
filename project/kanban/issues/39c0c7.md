## What to build

PDD027, "The Typed Handle" and "The Dynamic Handle". Replace `ResourceHandle` with Wasmtime's three handle types, each implementing the typed value traits (Wasmtime `resources/host.rs`, `host_static.rs`, `host_dynamic.rs`, `any.rs` at `v49.0.0-rc.1`).

- **`Resource<T>`.** A typed handle to a host resource of identity `ResourceType::host::<T>()`. `T` is a marker, so it is `Send + Sync` for every `T`. Not `Clone`. Wasmtime's four states (`host.rs:37-60`): a borrow, owned in no table, owned and moved into a guest, owned and in the host table. A second lowering as `own` fails with "host resource already consumed". The first lowering as `borrow` puts it in the host table so the borrow is tracked. Methods: `new_own`, `new_borrow`, `rep`, `owned`, `try_from_resource_any`, `try_into_resource_any`. Its type check accepts `own` or `borrow` of identity `host::<T>()` and never a guest resource.
- **`ResourceDynamic`.** The same handle for a `host_dynamic` type, carrying the `u32` of its type: `new_own(rep, ty)`, `new_borrow`, `rep`, `ty`, `owned`, `try_from_resource_any`, `try_into_resource_any`. Its type check accepts any `host_dynamic` type, and its lowering compares the `u32`.
- **`ResourceAny`.** The dynamic handle, replacing `ResourceHandle`. It holds a host-table index, the identity, and whether it is owned. It keeps today's generation and rep checks (the `Stale` and `RepMismatch` refusals). Methods: `ty`, `owned`, `resource_drop(store)`, `try_from_resource`, `try_into_resource`. Its type check accepts any `own` or `borrow`. Its lowering compares the identity and fails with the ABI error for a handle of the wrong resource type.
- **`Val`.** `Val::Own` and `Val::Borrow` become `Val::Resource(ResourceAny)`, with own or borrow read from `owned()`.
- **Removal.** `ResourceHandle`, `Store::resource_new`, `StoreContext::resource_new`, `HostCall::resource_new`, and `Store::resource_drop`. Move every caller (baseline tests, conformance, smoke, demo, Zena host) to the new handles.

## Acceptance criteria
- [x] A resource crosses as `Resource<T>` on both targets. The host makes a handle with `Resource::new_own` and passes it to a guest as an `own`. A host function then receives the guest's `borrow` of it. The rep matches at each step. A second lowering of the same owned handle as an `own` fails with "host resource already consumed".
- [x] A resource crosses as `ResourceDynamic`. The host registers `host_dynamic(1)` and `host_dynamic(2)`, and passes a handle of each to a guest and back. The rep and type match at each step. A handle of type 1 fails to lower where the component declares type 2.
- [x] A resource crosses as `ResourceAny`. The host receives an owned guest resource as `ResourceAny` and passes it back. It receives a second one and releases it with `resource_drop`, and that destructor runs once. A `ResourceAny` of the wrong type fails when lowered. `try_into_resource` succeeds for the right `T` and fails for another.
- [x] A type check compares resources by identity. Two interfaces each declare a resource named `error`, registered with `host::<A>()` and `host::<B>()`. A typed host function taking `Resource<A>` links to a function of the first and fails to link to a function of the second.
- [x] The host table refuses a stale handle: a `ResourceAny` whose slot was freed and used again fails with "host-owned resource was already de-allocated".
- [x] A resource type has one identity in every interface. With `host::<T>()` registered under interfaces A and B, a function of A returns an `own` to the host, the host passes it to a function of B, and the rep matches.
- [x] `ResourceHandle`, `Val::Own`, `Val::Borrow`, and every `resource_new` no longer appear in `public-api.txt`.
- [x] `lint` passes, and `tests all` is green on both targets with the conformance summary unchanged.

## Notes

- 2026-10-16 (from 3e9e67): restore `baseline_wasi_http_handler::it_answers_a_request_with_its_body_and_trailers`'s `own<fields>` inside the request's trailers future (the test sends `Ok(None)` for now), and the demo's `TrailersOutcome` carrying a `fields` handle, once `Resource<T>`/`ResourceAny` implement the typed value traits.
- 2026-10-16: the handles live in `rust/wcmp/src/resource/{host_static,host_dynamic,resource_any}.rs`.
  - `Resource<T>` and `ResourceDynamic` share a `HostHandle` with Wasmtime's four states, which are two `AtomicU32`s with the sentinel generations `BORROW`, `NOT_IN_TABLE`, and `TAKEN`.
  - The crossing is `lower_host_resource`/`lift_host_resource` and `lower_resource_any`/`lift_resource_any` in `src/abi/{lower,lift}.rs`. The typed impls are in `src/typed/impls/resources.rs`.
  - Messages follow Wasmtime: "host resource already consumed", "cannot lower a `borrow` resource into an `own`", and "resource type mismatch" for a conversion. All of these are the invalid-handle ABI cause. A lowering against the wrong declared type keeps the unregistered-resource-type cause.
  - `tests/baseline_typed_resources.rs` covers the first five criteria, one test each or more. The sixth, one identity in every interface, is `baseline::resources::it_shares_a_single_resource_type_across_two_imported_interfaces`, now over the new handles.
- 2026-10-16: `ResourceAny` keeps the rep beside the index, so the `Stale` and `RepMismatch` refusals stay. It packs `owned` and "runs a destructor" below the generation, so a `Val` stays 32 bytes and the copy budget's `LIST_ELEMENT_COST` is unchanged. The host table's generations wrap at 2^30 for this.
- 2026-10-16: differences from Wasmtime, for review:
  - A borrow's `ResourceAny::resource_drop` checks the entry and leaves it. The entry goes when the call that lent it ends, because the scope's lender list names it.
  - A `ResourceAny` made from a typed handle runs no destructor when released, as in Wasmtime. Handles a guest gives the host run theirs.
  - With `Store::resource_new` gone, a host can no longer mint a handle of a guest-defined type, also as in Wasmtime. Unit tests mint through a `#[cfg(test)]` `mint_own`.
- 2026-10-16: callers moved to the new handles: baseline unit tests, conformance, smoke, bench, and demo.
  - Restored the wasi-http trailers `own<fields>`: the test now sends `Ok(Some(Resource::new_own(2)))`.
  - The demo's `TrailersOutcome` is now `Result<Option<ResourceDynamic>, ErrorCode>`, and no hand impl of the typed traits remains outside `rust/wcmp/src`, which closes b75d76's last box.
  - Two `baseline::resources` tests asserted that a refused host mint names the type it asked for. Without a mint entry the lowering refuses, so they now assert the result position and the declared slot. Wasmtime names no type here.
  - The smoke `disposal` scenario and `baseline_poisoned_store` now get the handle they release back from the guest, since a host-made handle runs no destructor.
  - The demo now takes an `own` argument's entry out of the host table when it reads the rep, where it used to leave it there.
- 2026-10-16: `lint` is green, and so is `tests all` on rmlrsmqy: native 1778, web 1765, wasmi 1485, fidelity 264/267/264, demo 69/69, Zena Browser 18/18. The conformance progress record is unchanged. `public-api.txt` no longer lists `ResourceHandle`, `Val::Own`, `Val::Borrow`, or any `resource_new`.
