## What to build
At the moment the store is poisoned, discard two kinds of work:

- Every queued guest work item, such as a callback, a start item, or a ready thread.
- Every pending host future: host `async` functions, stream and future producers, and consumers. Each future is dropped.

```text
fn poison(store, trap):
    store.poisoned = true
    store.work_items.clear()         // no guest code runs again
    store.host_tasks.clear()         // each host future is dropped here
    return trap                      // the polling driver reports it
```

The task and subtask records stay until the store drops, as PDD018 states for every record. A later driver meets no stale work, so it fails only for an entry it makes itself.

This is a stated departure from Wasmtime, which keeps its queued items and host futures and runs them in a later `run_concurrent`. The polyfill discards them because the reference permits no guest code after a trap.

A future's `Drop` can reach the store through its accessor. Drop the discarded futures where host code is allowed to run, with no store lock held, so a `Drop` that touches the store neither deadlocks nor panics.
