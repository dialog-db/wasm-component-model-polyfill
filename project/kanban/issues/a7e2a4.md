## What to build

Port Wasmtime 50's `run_concurrent_yields_during_high_priority_work`
(`tests/all/component_model/async.rs` at `v50.0.0`). The test spawns 256 store
tasks that are ready at once, and a host task on the host executor. On a
single-threaded executor, the host task runs before every store task has
finished, because the driver gives the executor a turn after 128 turns without
a yield.

The test needs `Store::spawn`, which the polyfill lacks. This criterion was
split out of the card for the turn budget, whose other port passes.
