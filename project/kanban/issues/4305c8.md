## What to build
Remove `refuse_async_import` and `refuse_async_extern` from `src/executor/translate.rs` so the type projection accepts an async-typed import: `FunctionType.async_` is true on an imported function's type, and a host reads it through the component's import types as it reads it on an export today. Extend `LoweringSpec` in `src/executor/ir.rs` with the lower kind (`LowerKind` in `src/concurrency/lower_kind.rs`), read from the `async` option of the `canon lower`, and make `derive_runtime_func_type` in `src/executor/trampoline.rs` derive the core signature of an asynchronous lower per the reference's flattening for its lower: at most four flat parameters, one `i32` pointer instead when the flattened parameters exceed four, the result always through a pointer parameter when the type has one, and one `i32` result, the status word. A synchronous lower keeps the signature of PDD008. Validation requires the `memory` option on an asynchronous lower, and translation of one without it fails with a structured error. The trampoline built for an asynchronous lower fails when called with `Error::Unsupported` naming the asynchronous host call until the call path lands, so a component that lowers asynchronously instantiates once its imports link. The lift and the lower are separate axes, and the docs on `FunctionType::async_` and `LoweringSpec` say so. The refusals of the translation section stay as they are: `subtask.cancel`, `task.cancel`, `canon lift async` without a callback, the stream, future, and error-context built-ins, every thread built-in other than `thread.yield`, and the table initializer of `thread.new-indirect` still fail with `Error::Unsupported`.

## Acceptance criteria
- [ ] A repository test reads `async_` as true on an imported function's type of a component whose import is async-typed, and the component's translation no longer fails for that import.
- [ ] Unit tests prove the derived core signature of an asynchronous lower for four cases: flat parameters within four, parameters beyond four, a result, and no result; a synchronous lower's signature is unchanged.
- [ ] An asynchronous lower without the `memory` option fails at translation with a structured error.
- [ ] `lint` passes and `tests all` is green on both targets, and any directive that starts passing has its line removed from the expected-failure list.
