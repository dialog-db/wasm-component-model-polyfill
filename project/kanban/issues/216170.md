## What to build
Support `include_component_type: true` in `wcmp::bindgen!`, as Wasmtime does: emit a `COMPONENT_TYPE` constant that holds the binary-encoded world (via `wit-component` at compile time). PDD028 refuses this option today.

## Acceptance criteria
- [ ] The macro emits `COMPONENT_TYPE` with the same bytes Wasmtime's macro emits for the same WIT at the pinned version.
- [ ] The PDD028 ledger row moves to matched, and the ledger test and corpus test pass.
- [ ] `wit-component` stays a dependency of the macro crate only; no runtime or browser binary gains it.
- [ ] `lint` passes and `tests all` is green.
