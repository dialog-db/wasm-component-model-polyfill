## What to build

Non-blocking findings from the independent review of 9c6f97 (the drop rule restored, landed `3ea3b3a10`):

- **No provider test parks a thread.** In `it_takes_the_stop_of_a_resume_whose_driver_was_dropped_on_the_next_call`, the next call's first poll runs before the resumed microtask, so `adopt` re-grants a running flight; in `it_runs_the_thread_of_a_dropped_call_in_a_later_call` the flight had already stopped. Only the contract test `it_takes_up_a_resumption_whose_wait_dropped` reaches Parked → adopt. The reviewer proved the path with three probes (yield 16 microtasks after the drop, then the next call returns 7 with notes `[99,99]`; two consecutive dropped drivers; a dropped store with a parked thread). Add them to `rust/wcmp/src/baseline/provider_threads.rs`.
- **`Resumption::stop` spends the handle on any error** (`wcmp-wasm-core/src/call/resumption.rs:80-82`): a claim refusal (HOSTING), a Wasmi slot-count `TypeMismatch` (`wasmi/src/resumption.rs:36-44`), or a resolver that throws in `adopt` all lose the call; the last also leaves the flight in `Calls.running` with its cell kept (`calls.rs:349-354`). Keep the handle on a refusal a host can retry.
- **A remaining trap path.** A flight's own host function that drops its wait's future traps `TAKEN_BACK` at the next host call in the same stretch (`calls.rs:617-620`), because parking happens only at `resumed`. Park there too, or document why not.
- **Missing tests.** A forget-plus-global test on the two-step `Resumption::stop` path; dropping a parked `Resumption` and then the store, checking nothing leaks. The middle assertion of `it_runs_the_thread_of_a_dropped_call_in_a_later_call` pins a scheduling order PDD018 does not fix; loosen it.
- **PDD.** PDD025's Host Suspension section describes only the one-step API and no drop semantics; the owner extends it to cover `Resumption`, `start_resumable`, `start_resume`, `stop` and `BackendResumption`.

## Acceptance criteria
- [ ] A provider test parks a thread before the next driver adopts it, in the browser.
- [ ] A retryable refusal keeps the resumption; a thrown resolver leaves no running entry.
- [ ] The same-stretch trap path parks or is documented.
- [ ] The missing tests exist, and the brittle assertion is loosened.
- [ ] `tests all` and `lint` pass.
