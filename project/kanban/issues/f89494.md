## What to build

PDD028, "Errors". `trappable_error_type` and `anyhow: true` (Wasmtime `lib.rs:2932-2965` and `3407-3420` at `v49.0.0-rc.1`).

- **`trappable_error_type`.** Acts only on a function with the `trappable` flag. A function returning `result<T, E>` returns `Result<T, MyError>`. The interface trait gains `convert_e(&mut self, MyError) -> wcmp::Result<E>`; an `Ok(e)` reaches the guest as the WIT error value, and an `Err` traps.
- **`anyhow: true`.** Generated signatures use `anyhow::Result<T>`. The registration turns an `Err` into an `Error`: an `anyhow::Error` that holds a polyfill `Error` gives that `Error`; any other becomes the source of an `Error::Host`.

## Acceptance criteria
- [x] `trappable_error_type` converts a host error: `convert_e` returns `Ok` for one host error and the guest receives the WIT error value; it returns `Err` for another and the guest traps. On both targets.
- [x] `anyhow: true` keeps the error: a `trappable` method returns an `anyhow::Error` of a host type, and a second returns an `anyhow::Error` that holds `Error::ResourceTable`. The first call returns `Error::Host` whose source downcasts to the host type. The second returns `Error::ResourceTable`.
- [x] A `trappable_error_type` entry for a type that no `trappable` function returns fails the compile, as in Wasmtime.
- [x] `lint` passes, and `tests all` is green on both targets with the conformance summary unchanged.


## Delivery notes

Delivered on the host in `feat(bindgen): Generate exports, async calls, resources, with, and errors` (with 9723b5 in `fix(linker): Link a used resource with no registration of its own` before it).

- `trappable_error_type` fails the compile when its WIT path names no type, as Wasmtime does (`failed to locate a WIT error type…`). Wasmtime does not fail an entry whose type exists but which no trappable function returns, and neither does the polyfill: criterion 3 is read as Wasmtime's rule.
- A store-flag method's `convert_*` reaches the view again after the method's `Access` is spent, through a hidden `wcmp::__private::reborrow` of the call's store context; an async method's goes through its accessor's `with`.
- Tests: `rust/wcmp-bindgen-tests/tests/errors.rs` and a refusal unit test.
