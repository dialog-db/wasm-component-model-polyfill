## What to build

PDD028, "Errors". `trappable_error_type` and `anyhow: true` (Wasmtime `lib.rs:2932-2965` and `3407-3420` at `v49.0.0-rc.1`).

- **`trappable_error_type`.** Acts only on a function with the `trappable` flag. A function returning `result<T, E>` returns `Result<T, MyError>`. The interface trait gains `convert_e(&mut self, MyError) -> wcmp::Result<E>`; an `Ok(e)` reaches the guest as the WIT error value, and an `Err` traps.
- **`anyhow: true`.** Generated signatures use `anyhow::Result<T>`. The registration turns an `Err` into an `Error`: an `anyhow::Error` that holds a polyfill `Error` gives that `Error`; any other becomes the source of an `Error::Host`.

## Acceptance criteria
- [ ] `trappable_error_type` converts a host error: `convert_e` returns `Ok` for one host error and the guest receives the WIT error value; it returns `Err` for another and the guest traps. On both targets.
- [ ] `anyhow: true` keeps the error: a `trappable` method returns an `anyhow::Error` of a host type, and a second returns an `anyhow::Error` that holds `Error::ResourceTable`. The first call returns `Error::Host` whose source downcasts to the host type. The second returns `Error::ResourceTable`.
- [ ] A `trappable_error_type` entry for a type that no `trappable` function returns fails the compile, as in Wasmtime.
- [ ] `lint` passes, and `tests all` is green on both targets with the conformance summary unchanged.
