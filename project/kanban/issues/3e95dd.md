## What to build

PDD027, "Resources Inside Derived Types". A derived record or variant can hold `Resource<T>`, `ResourceDynamic`, and `ResourceAny` fields, treated as any other field. Prove the edges the PDD states:

- A `borrow` that a host function receives inside a derived type is valid until the host function returns.
- A lift that fails after it moved an `own` field out of the guest's table traps and poisons the store (PDD023), so the moved handle is unreachable.

## Acceptance criteria
- [ ] A derived type holds `own` and `borrow` fields on both targets. A record has a `Resource<T>` field and a `ResourceAny` field. It crosses into a host function with `borrow` fields and out of a host function with `own` fields, and each rep matches.
- [ ] The host keeps the `ResourceAny` borrow past the return of the host function and lowers it into a later call. That lowering fails with the invalid-handle ABI cause.
- [ ] A guest passes a host function a record whose `own` field lifts before a string field that holds invalid UTF-8. The call traps, and a later call into the store fails with the cannot-enter error of the poisoned store.
- [ ] `lint` passes, and `tests all` is green on both targets with the conformance summary unchanged.
