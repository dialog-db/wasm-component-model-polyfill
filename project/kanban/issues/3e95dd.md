## What to build

PDD027, "Resources Inside Derived Types". A derived record or variant can hold `Resource<T>`, `ResourceDynamic`, and `ResourceAny` fields, treated as any other field. Prove the edges the PDD states:

- A `borrow` that a host function receives inside a derived type is valid until the host function returns.
- A lift that fails after it moved an `own` field out of the guest's table traps and poisons the store (PDD023), so the moved handle is unreachable.

## Acceptance criteria
- [x] A derived type holds `own` and `borrow` fields on both targets. A record has a `Resource<T>` field and a `ResourceAny` field. It crosses into a host function with `borrow` fields and out of a host function with `own` fields, and each rep matches.
- [x] The host keeps the `ResourceAny` borrow past the return of the host function and lowers it into a later call. That lowering fails with the invalid-handle ABI cause.
- [x] A guest passes a host function a record whose `own` field lifts before a string field that holds invalid UTF-8. The call traps, and a later call into the store fails with the cannot-enter error of the poisoned store.
- [x] `lint` passes, and `tests all` is green on both targets with the conformance summary unchanged.

## Notes

- 2026-10-16: no library change was needed. The derive already treats `Resource<T>` and `ResourceAny` as any other field. `tests/baseline_typed_resource_fields.rs` has three tests:
  - A record of two `borrow`s goes into a host function, and a record of two `own`s comes out of one. The reps are checked through the guest's drops of what it received.
  - A `ResourceAny` borrow kept past `take-borrows` fails to lower into a later call, with the invalid-handle cause.
  - A record whose `own` field lifts before a string of `0xff` fails the call. The host function never runs and no destructor runs, and the next call fails with `TaskCause::CannotEnter`.
- 2026-10-16: `lint` is green, and so is `tests all` on vlllrwrs (e3d75d and 3e95dd together): native 1784, web 1772, wasmi 1491, fidelity 264/267/264, demo 69/69, Zena Browser 18/18. The conformance progress record is unchanged.
