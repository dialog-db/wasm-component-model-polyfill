## What to build

The `repository` field names `github.com/cdata/wasm-component-model-polyfill`.
The repository is `github.com/dialog-db/wasm-component-model-polyfill`.

docs.rs builds for `x86_64-unknown-linux-gnu` by default. On that target,
`wcmp-wasm-core-web` is empty, and `wcmp` leaves out its browser half. Each
published crate gets `[package.metadata.docs.rs]` with the targets that hold
its code. The browser backend defaults to `wasm32-unknown-unknown`.

## Acceptance criteria

- [ ] Every published crate names the `dialog-db` repository.
- [ ] The docs.rs metadata of `wcmp-wasm-core-web` builds its documentation
      for `wasm32-unknown-unknown` by default.
- [ ] `wcmp` documents both targets on docs.rs.
- [ ] A local rustdoc run for each docs.rs target succeeds.
