## What to build
Add a root accessor on `Linker` that returns the existing registration view for the root namespace. Make the resolver's plain-named branch consult the root registration and apply the link-time signature check; an unmatched plain-named import surfaces `LinkError::UnresolvedImport`. Make the executor's lowering and resource lookups accept a plain-named import that resolved through the root. Un-stub `it_supports_a_plain_named_top_level_import`.

## Acceptance criteria
- [ ] `it_supports_a_plain_named_top_level_import` passes on every target.
- [ ] A plain-named import with no root registration fails with `LinkError::UnresolvedImport` naming the import.
- [ ] The corpus lines that cite `plain-named imports require host-item registration` become real results and the list is regenerated.
