## What to build

PDD026, "Zena Compatibility Scenarios", and PDD024's "Compiler Scenarios". Extend the Zena compatibility suite so that a scenario can run the compiler component and then run what it returns.

- **`read-source` in the test host functions.** It answers a path with the text of that file from the toolchain source bundle, or with none. It works on every subject, the browser included.
- **A compiler scenario's build** uses the compiler component from the compiler build, not `zena build` of a scenario source.
- **A returned component.** An expectations entry can name a component that a previous call returned. The runner takes the `list<u8>` of that call's `ok` result, parses it as a component, links it with the test host functions, and instantiates it. Later entries call its exports. The stages apply in the same way: a parse failure records `parse`, a missing import records `link`, and so on.
- **Byte equality.** A polyfill subject passes a `compile` call when it returns the same bytes as the Wasmtime run. Record the Wasmtime bytes in a form that the record check can compare without storing whole components in the record (a digest is enough).

Compiles are slow on native subjects (0.8 to 9.3 seconds each under Wasmtime's default collector). Keep the lane inside its time budget. The Wasmi subject has no GC, so it records an early stage for these scenarios, as it does for the other GC scenarios.

## Acceptance criteria
- [ ] A returned component goes through the stages. A test gives the runner a scenario whose compiled program imports an interface that the test host functions lack. The record shows `link` for that scenario.
- [ ] A test gives the runner a compiler scenario whose entry names the returned component. Every subject that reaches `run` instantiates that component and calls it.
- [ ] A polyfill subject whose `compile` result differs from the Wasmtime bytes fails that call.
- [ ] `read-source` answers from the bundle on the native and browser subjects, and answers none for a missing path.
- [ ] `tests all` and `lint` pass.
