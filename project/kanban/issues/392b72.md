## What to build

PDD026, "Elements": "What an Author Writes" (class form), "What the Helper Does", "Lifecycle", and "One Instance Per Tag".

- **Authoring library, first part.** The `demo:element` Zena module with the `Element` base class: `attributes`, `styles`, `render`, `on`, and `attribute`. `View`, `h`, and `emit` can be stubs here; the render and event cards fill them in.
- **Element world.** The `element` interface, the `host` interface, and the `element-component` world from PDD026, in the demo's source bundle. Every export is `async func`. The world imports every interface the page supplies, and the host framework links each one, used or not.
- **Glue.** The helper writes a Zena module that imports the author's definition and exports `element`. It keeps a table from each id to one object of the author's definition. `create` returns the id. `disconnected` removes the object.
- **Helper.** `define_element(tag, source)` compiles the glue as the entry module with the author's source as a file beside it, returns the diagnostics as an error on failure, makes one `Store` and one instance for the tag, and registers a custom element class whose `observedAttributes` come from `observed-attributes`.
- **Lifecycle.** `connectedCallback` calls `create` with the current attributes when the element has no id, then `connected`. `attributeChangedCallback` calls `attribute-changed` only when the element has an id. `disconnectedCallback` calls `disconnected`, and the element forgets its id.
- **Counts.** The host framework reports, per tag, the count of connected elements and of instances. The drawer shows them later.

## Acceptance criteria
- [ ] The lifecycle callbacks map to calls. A test sets an attribute before it adds an element to the document. `create` receives the attribute.
- [ ] A test removes an element and adds it again. The element gets a new id.
- [ ] One instance serves every element of a tag. A test adds fifty elements of one tag and then removes forty. The host framework reports one instance throughout, and fifty and then ten connected elements.
- [ ] A source that fails to compile makes `define_element` return the diagnostics.
- [ ] `tests all` and `lint` pass.
