## What to build
Vendor `js_wasm_runtime_layer` 0.7.0 as a path dependency under the workspace (with upstream's license and a note that names the upstream commit and the two patches) and route it through `[patch.crates-io]`. Patch the module parser to accept memory, global, and tag imports, and patch the host-function shim to throw a JavaScript exception when the host returns `Err(_)`, so the guest traps and the error reaches the polyfill's `Func::call`. Keep the shape of upstream so the patch can be dropped when upstream catches up.

## Acceptance criteria
- [ ] A core module that imports a global or a memory instantiates in the browser.
- [ ] `it_propagates_a_host_function_error_through_the_call` runs on the web target without a gate and passes.
- [ ] The libc-shared-instance linking test runs on the web target without a gate and passes.
- [ ] The vendored copy carries upstream's license and a patch note.
