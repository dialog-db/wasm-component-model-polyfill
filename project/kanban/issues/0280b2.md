## What to build
A component may export an instance under a plain name (`a`, `i`, `c`) rather than a WIT interface identifier. The translator parses every exported instance name as an `InterfaceIdentifier` and rejects the rest at `src/executor/translate.rs` ("instance exports with a plain name"). Wasmtime accepts them: `Instance::get_export` walks any name. Imports already got root-namespace treatment; exports need the mirror. Make a plain-named export instance reachable through `Instance::exports()`, alongside the identifier-keyed lookup, and keep the type projection for its items.

Parity: the same host code runs natively and in the browser; the change is in the translator and the instance export model, which are shared, so add the test to a cross-target baseline file.

Corpus: 13 `deferred-feature` lines in `cm/validation/external-visibility.wast`, `cm/validation/attributes.wast`, `wasmtime/instance.wast`, and `wasmtime/aliasing.wast` flip, plus the cascades behind them.

## Acceptance criteria
- [x] A component exporting an instance named `a` instantiates, and the host reaches its functions through `Instance::exports()` on both targets.
- [x] Every `instance exports with a plain name` line is removed from `expected-failures.txt`, and the corpus is regenerated.
- [x] `tests all` passes on both targets.
