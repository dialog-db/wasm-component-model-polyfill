## What to build

PDD027, "The Three Traits", "Crossing Without Val", and "The Type Check". Replace `ComponentValue`, `ComponentParameters`, and `ComponentResult` (`src/linker/component_value.rs`) with Wasmtime's `ComponentType`, `Lift`, `Lower`, and `ComponentNamedList`, exported flat at `wcmp::`.

- **Traits.** Every method and constant is `#[doc(hidden)]`. `ComponentType` carries compile-time layout constants (`SIZE32`, `ALIGN32`, the flat count) and the type check. All three require `Send + Sync` on every target.
- **Context.** A public lift context and lower context in a hidden module, so that a derive in another crate can implement the traits. Each wraps what `BoundaryContext` does today: one read for each contiguous range of guest memory, one write for each lowered list, `realloc` in Canonical ABI order, and the copy budget.
- **Tuples.** `ComponentNamedList` for tuples of 0 to 17 values, for parameters and for results. `TypedFunc<P, R>` takes a result tuple, `TypedFunc<(u32,), (u32,)>`, and `func_wrap`/`func_wrap_concurrent` return one.
- **No `Val` on the typed path.** `TypedFunc::call`, `call_concurrent`, `func_wrap`, and `func_wrap_concurrent` lift and lower directly in both directions (today the host functions go through `from_vals`/`into_val`, `src/linker/linker_instance.rs:263-265, 418-423`). The result of an export lifted `async` is lifted directly from `task.return`'s arguments (today a `Val`, `src/instance/typed_func.rs:98-100`). The numeric list fast path stays.
- **The type check.** Walks the declared type and the Rust type together in Wasmtime's order (`func/typed.rs:2205-2340`): count, then field by field type then name, case by case name then payload. It runs at `Func::typed` and at link time only. The per-call `expect_declared` (`component_value.rs:921`) goes. A mismatch is `Error::TypeMismatch` whose position carries a structured path: parameter or result by index, field or case by the component's name, list element, map key or value, option/result/stream/future payload, tuple member by index.
- **Built-in forms.** Implement the traits for every type that `ComponentValue` covers today: the scalars, `char`, `String`, `Vec<T>`, `[T; N]`, `HashMap<K, V>`, `Option<T>`, `StreamReader<T>`, `FutureReader<T>`, and `ErrorContext`.
- **Removal.** No `to_val`, `from_val`, or `value_type` on a typed value. The hand-written `ComponentValue` impls (`baseline/error_context_transfer.rs`, `tests/zena/host.rs`, `tests/baseline_wasi_http_handler.rs`, `wcmp-demo/src/http_types/mod.rs`) implement the new traits by hand until the derive exists.
- **Call sites.** Move every typed call and host function in the repository (tests, smoke, demo, bench, scenario crates) to result tuples.

## Acceptance criteria
- [x] `ComponentValue`, `ComponentParameters`, and `ComponentResult` no longer appear in `public-api.txt`. `ComponentType`, `Lift`, `Lower`, and `ComponentNamedList` do, with no visible methods.
- [x] A typed call and a typed host function each pass a tuple of 17 values and return a tuple of results on both targets.
- [x] The typed path builds no `Val`: a test counts allocations around a typed `Vec<String>` echo through `TypedFunc` and through a `func_wrap` host function, on both targets. The count is the same for 16 and for 4,096 strings, apart from the strings and the result list themselves.
- [x] An export lifted `async` returns a typed result with no `Val`, proved by the same allocation count.
- [x] A type mismatch is refused at `Func::typed` with `Error::TypeMismatch`, and no call reaches the guest. The path names the first wrong part, for example a `list<u8>` element where the export declares `list<u16>` in result 0.
- [x] A type mismatch is refused at link time for a `func_wrap` host function. The position names the interface, the item, and the path.
- [x] A test counts the runs of the type check around 1,000 calls of one typed function. The count does not change.
- [x] `lint` passes, and `tests all` is green on both targets with the conformance summary unchanged.

## Notes

- 2026-10-16: Delivered in `feat(typed): Replace ComponentValue with ComponentType, Lift, and Lower`. The traits live in `src/typed/` (each in its own module), with the hidden lift and lower contexts, `TypeChecker`, and `TypeCheckError` re-exported at `wcmp::__private` together with `CanonicalAbiInfo`, `CoreVal`, and the case and layout helpers a derive or a hand impl calls.
- A function's lists cross as the tuple, member by member against the declared function type (`NamedTypes`), so a failure names `argument i` or `result`, and the type check's path starts at `Parameter(i)` or `Result(i)`. `TypePathStep`, `TypeRendering::Rust`, and `TypeRendering::Name` are new; `TypedConversion` and both `HostFunctionRegistration` positions gained a `path`.
- An export lifted `async`: the typed call gives its task a lift, which `task.return` runs in place of lifting a `Val`; the task resolves with no value and the call takes its tuple from the lift's slot.
- Typed host functions: the registration lifts its own parameter tuple (`HostParams::Typed`), and its results lower themselves (`HostResults::Typed`); a concurrent one's future keeps its results in a slot the host task's lowering reads, so `HostTask` is unchanged. The linker runs the registration's type check with the imported resources' identities.
- Host streams and futures: the end's record keeps an `EndPayload`, the declared type with resolved identities or the host's Rust type (`TypeId` and its type check), as Wasmtime's `PayloadType`. Producers lower and consumers lift through the traits; a host-to-host pipe moves the items as the producer's own `Vec`, as Wasmtime's requires one Rust type.
- Criterion 3 (allocations): each lowered string calls the guest's `cabi_realloc`, which the Canonical ABI runs as a task of its own, and its records cost the host about 4 allocations per call on either path (5 in the browser). That is not a `Val`, so the tests measure it with an export that only lowers the list (`count-strings`) and assert that each echo costs exactly one allocation per lifted string beyond it, the same at 16 and at 4,096.
- Wasmtime 49's `ErrorContext` does convert to and from a `Val` (`into_val`, `from_val(store, &Val)`), so the polyfill's has the same two methods. PDD027 says no typed value converts; this one is Wasmtime's own exception. Owner: fine to amend the PDD sentence?
- Coverage moved to 39c0c7: `baseline_wasi_http_handler`'s request trailers future no longer carries an `own<fields>` (a typed future payload cannot hold a handle until `Resource<T>`), and the demo's `TrailersOutcome` lowers only `ok(none)`; both come back with the typed handles.
- Gate: `lint` green; `tests all` green on every lane, conformance totals unchanged (native 2415, browser 2410, Wasmi 2355 of 2446), demo 69/69.
- 2026-10-16 (review 1): a typed host function now gates the address of spilled parameters as the untyped path does ("pointer not aligned", "pointer size overflow", "pointer out of bounds"), as the spec's `lift_flat_values` and Wasmtime's `validate_inbounds_dynamic` do. So does a spilled `task.return`, typed and untyped. The shared gate is `abi::check_spilled_address`.
- 2026-10-16 (review 1): the allocation tests now also measure `list<tuple<u32, u32>>`, whose `Val` form allocates per element and whose typed form does not, so they tell the typed path from a `Val` path.
- 2026-10-16 (review 1): `Func::ty()` resolves each resource to the identity the instance gave it, as Wasmtime's `Func::ty` does through `InstanceType`. It returns an owned `FunctionType`.
- 2026-10-16 (review 1): `StreamReader<()>` and `FutureReader<()>` type-check against a stream or future with no payload, as Wasmtime's `typecheck_payload` does with `IS_RUST_UNIT_TYPE`.
- 2026-10-16 (review 1): the host-function payload types moved one per module (`host_signature`, `host_args`, `host_results`, `typed_results`, `host_params`, and `host_payload`), and so did `HostPayload`.
- 2026-10-16 (review 1): a payload-less future that a guest wrote now reads as `FutureReader<()>`: `Source::read` lifts each `()` against an empty tuple instead of refusing a missing payload. The new tests found this.
