## What to build

PDD028, "Exports" for `async | store` and async functions (Wasmtime `tests/expanded/char_concurrent.rs:354-389` at `v49.0.0-rc.1`).

- An export with the `async` and `store` flags, and every WIT `async func` export, emits a `call_*` that takes an `impl AsAccessor` in place of the store and calls `TypedFunc::call_concurrent`.
- Under `async | store` the `call_*` takes owned parameters (`String`, `Vec<T>`), as Wasmtime's parameter mode does.
- The world-level `call_*` methods and the interface getters' `call_*` methods both follow the rule.

## Acceptance criteria
- [x] An invocation with `exports: { default: async | store }` emits `call_*` methods that take an `impl AsAccessor`. A call from inside `run_concurrent` with an accessor of a projection other than `HasSelf` returns the export's result, on both targets.
- [x] A WIT `async func` export emits the accessor form without any `exports` flag.
- [x] Under `async | store`, `call_*` takes owned parameters; without it, borrowed parameters.
- [x] `lint` passes, and `tests all` is green on both targets with the conformance summary unchanged.


## Delivery notes

Delivered on the host in `feat(bindgen): Generate exports, async calls, resources, with, and errors` (with 9723b5 in `fix(linker): Link a used resource with no registration of its own` before it).

- The accessor form takes `accessor: impl AsAccessor`, where Wasmtime 49's takes `&Accessor<_T, _D>`; both accept a reference to an accessor. Tests: `rust/wcmp-bindgen-tests/tests/async_exports.rs` (a non-`HasSelf` accessor inside `run_concurrent`, owned `String` under `async | store`, and a WIT `async func` export with no flag); `exports.rs` shows the borrowed `&str` form.
