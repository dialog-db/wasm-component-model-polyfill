## What to build

A typed call that takes borrowed arguments, as Wasmtime's `TypedFunc<(&str,), _>` does, without copying them on the host first.

Today a typed call keeps its arguments until the task it starts runs: `CallValues` is `Send + 'static` (`rust/wcmp/src/instance/call_values.rs`), because the start of the task is queued behind the entry gate of the export's instance. So `TypedFunc::call` takes only `'static` parameter tuples, and the `call_*` methods `wcmp::bindgen!` writes keep Wasmtime's borrowed parameters (`&str`, `&[T]`, `&T`) by copying each into an owned value before the call (found while delivering acefba). Wasmtime lowers the arguments into the guest during the call and copies nothing on the host.

Find a shape that lowers borrowed arguments before the call queues anything, or that holds the borrow for the length of a `call` whose future cannot outlive it, and keep `call_concurrent`'s owned arguments. Then make the generated `call_*` pass its borrows straight through, and `func_*` give Wasmtime's borrowed `TypedFunc`.

## Acceptance criteria
- [ ] `TypedFunc<(&str,), (String,)>::call` and `TypedFunc<(&[u32],), (u32,)>::call` work on both targets, with no host copy of the argument (an allocation-count test, as PDD027's).
- [ ] A generated `call_*` with a `&str` parameter makes no host copy of it.
- [ ] `lint` passes, and `tests all` is green on both targets with the conformance summary unchanged.
