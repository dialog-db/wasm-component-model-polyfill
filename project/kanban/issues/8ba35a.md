## What to build
A Rust partner component that links with Zena at run time, in both directions.

- A scenario can hold a partner's Rust source and its locked cargo manifest. The partner uses `wit-bindgen` against the same WIT world as the Zena side, as the Rust fixtures of the conformance suite do (`tests/corpus/fixtures/build.sh`).
- The build compiles the partner at test time with this workspace's Rust toolchain and the locked manifest. Nothing is committed. The partner's build does not depend on the `zena` input, so a move of the pin changes only the Zena side.
- Scenario 10: Zena imports from Rust at run time. Scenario 11: Rust imports from Zena at run time. Each passes a string across the link.
- Regenerate and commit the record lines.

## Acceptance criteria
- [ ] Scenarios 10 and 11 run under all three subjects.
- [ ] Both build the Rust partner from its locked manifest at test time.
- [ ] The partner's bytes do not change when the pin moves.
- [ ] The record holds lines for scenarios 10 and 11, and `tests zena` passes the gate.
- [ ] `tests native debug`, `tests web debug`, and `lint` pass.
