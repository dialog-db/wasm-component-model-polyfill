## What to build

Wasmtime 50 charges hostcall fuel when it lifts a `Val` (`c2741c9bb`,
GHSA-jqpg-j7w6-42pr). It charges one `Val` for each record or tuple field, for
each variant, option, or result payload, and the length of each field, case,
or flag name. The polyfill charges only lists, maps, and strings
(`abi/lift.rs:53`, `:548`, `:826`).

## Acceptance criteria

- [x] The charges match `values.rs` at `v50.0.0`, in memory lifts and in flat
      lifts.
- [x] A test shows a record lift refused at the budget on both targets, with
      no fuel spent.

## Review notes

- 2026-10-20: `feat: Charge hostcall fuel for records, variants, and names, as
  Wasmtime 50 does`. `VAL_COST` (32 bytes, the `Val` of a 64-bit host) for each
  record field, tuple element, and variant, option, or result payload, and one
  byte per name byte, in the memory and the flat lifts. A map entry keeps its
  64 bytes up front and lifts its key and value without the tuple charge, as
  Wasmtime's `load_map` does. Two new tests refuse a record one byte past the
  budget, through memory and through a flat slot, on both targets. The
  `list-and-string` test now counts its result tuple's 64 bytes.
