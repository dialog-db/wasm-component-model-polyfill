## What to build

PDD026, "Elements: What an Author Writes". The function form of an element: the author exports a function from attributes to a view, plus an optional event function. The function form keeps no state between renders. The glue detects which form the author's source exports and adapts it to the same `element` interface.

## Acceptance criteria
- [ ] The class form and the function form both work. A test defines one element in each form. Both render their attributes, and both handle a click.
- [ ] A function-form element without an event function compiles and renders.
- [ ] `tests all` and `lint` pass.
