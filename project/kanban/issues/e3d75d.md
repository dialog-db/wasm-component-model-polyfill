## What to build

PDD027, "ResourceTable". `wcmp::ResourceTable` with Wasmtime's API, names, and errors (`crates/wasmtime/src/runtime/component/resource_table.rs` at `v49.0.0-rc.1`): `new`, `with_capacity`, `is_empty`, `max_capacity`, `set_max_capacity`, `push`, `push_child`, `add_child`, `remove_child`, `get`, `get_mut`, `get_any_mut`, `delete`, `iter_entries`, `iter_children`, `iter_mut`. `push` returns a `Resource<T>` whose rep is the slot index.

The errors are cases of the existing `ResourceTableError` (`src/error.rs:1068`), which gains `NotPresent`, `WrongType`, and `HasChildren` beside `Full`, each with Wasmtime's message.

`push` and `push_child` require `T: Send + 'static` natively and only `T: 'static` on `wasm32`, following the `MaybeSend` precedent of `Store::new` and `HostFuture`. The table is a plain data structure and shares nothing with the store's host table.

## Acceptance criteria
- [x] `ResourceTable` matches Wasmtime. Each error occurs where Wasmtime gives it, on both targets:
  - `NotPresent` from `get` after `delete` of the same entry.
  - `WrongType` from `get` with a `Resource` of another `T` at the same index.
  - `Full` from `push` past `set_max_capacity`.
  - `HasChildren` from `delete` of a parent that has a child from `push_child`.
- [x] In the browser, `ResourceTable` holds a value that is not `Send` (for example a `JsValue`), and a `Resource` of it crosses into a guest as an `own` and back.
- [x] A registration whose destructor calls `delete` on the table frees the entry when a guest drops the handle.
- [x] `lint` passes, and `tests all` is green on both targets with the conformance summary unchanged.

## Notes

- 2026-10-16: `rust/wcmp/src/resource/resource_table.rs` follows Wasmtime's `resource_table.rs` at `v49.0.0-rc.1`: a free list, children per entry, and the default capacity of 1,000,000.
  - `ResourceTableError` gains `NotPresent`, `WrongType`, and `HasChildren`, with Wasmtime's messages.
  - `push` and `push_child` are split by target: natively `T: Send + 'static`, and on wasm32 `T: 'static`, as with `HostFuture`. A `MaybeSend` bound would have named the runtime layer in a public signature, which the `public-api` check refuses.
  - `iter_entries` walks the slots once in key order rather than with Wasmtime's `unsafe` cast.
  - The table has no debug tombstones (Wasmtime's `DELETE_WITH_TOMBSTONE` is `false`).
- 2026-10-16: the unit tests in `resource_table.rs` give each error on both targets. Note that a push past `set_max_capacity` still fills a freed slot, as in Wasmtime.
  - `tests/baseline_resource_table.rs` has a registration whose destructor deletes the entry when a guest drops the handle.
  - It also has a browser-only test that pushes a `JsValue` and crosses its `Resource<JsValue>` into a guest and back.
