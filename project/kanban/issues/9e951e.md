## What to build
Let a task that must not block reach the provider, but only to resume the threads of its own instance. This revises the statement of PDD020 that such a task never reaches the provider; today `provider_serves` in `src/concurrency/suspend_seam.rs` sends it to the nested turn alone.

A task must not block when it is a sync-typed call, a start function, or a resource destructor. Its thread never lets the store run other work. When it blocks, the try part runs the ready threads of the task's own instance from inside itself, as `canon_lift` runs them (`definitions.py`):

- A queued item of that instance runs as the nested turn of PDD020, limited to the instance.
- A suspended thread of that instance resumes through the provider, from inside the try part. Under JSPI that resumption suspends the trampoline's thread as well and runs only what the reference runs.
- The block fails with the cannot-block cause when no thread of the instance is ready.

Wasmtime runs the same rule through `switch_or_trap_if_may_not_suspend`.
