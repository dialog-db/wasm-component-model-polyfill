## What to build

The crate's in-module unit tests do not run in the browser. `wcmp_macros::test` (`rust/wcmp-macros/src/lib.rs`, around lines 72-80) rejects a non-async function, so every synchronous unit test in `src/` is a plain `#[test]`, and the wasm32 runner collects only `wasm_bindgen_test` functions, so the web lanes skip them silently — 88 of them at the last count (native lanes ran 407 tests, web lanes 319), including the scheduler's queue-order tests. Give `wcmp_macros::test` a synchronous arm that expands to `#[test]` natively and `#[wasm_bindgen_test]` on wasm32 (the pair `#[cfg_attr(not(target_arch = "wasm32"), test)]` + `#[cfg_attr(target_arch = "wasm32", wasm_bindgen_test::wasm_bindgen_test)]` that `src/concurrency/suspend_seam.rs` uses by hand), convert the existing plain `#[test]` functions under `src/` to it, and make the web lane's count move by that many. Leave a test that genuinely cannot run in the browser on `#[test]` with a comment saying why.

## Acceptance criteria

- [ ] `wcmp_macros::test` accepts a synchronous function and runs it in both lanes.
- [ ] The web lane's test count rises by the number of converted tests, and every converted test passes in headless Chrome.
- [ ] `lint` passes and `tests all` is green on both targets with the conformance summary unchanged.
