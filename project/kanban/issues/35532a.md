## What to build
Revise PDD001 so that it describes the environment the sibling projects use: katsuobushi pinned to a release tag with `nixpkgs.follows`; the Rust build helpers, Markdown tooling, and project board taken from `katsuobushi.lib.rust`, `lib.markdown`, and `lib.project` instead of local copies; the design corpus under `project/design/` with the katsuobushi PDD template (six sections, including Test Cases); the board under `project/kanban/`; and a menu shaped like the sibling projects (`build <profile>`, `tests <target> <profile>`, `lint`, `markdown`, `project`). State that every build and test routine is a Nix derivation the menu drives. Keep the document in plain English per `design/README.md`.

## Acceptance criteria
- [ ] PDD001 names the katsuobushi release the project pins and the three libraries it consumes.
- [ ] PDD001 places PDDs under `project/design/` and the board under `project/kanban/`.
- [ ] PDD001 lists the menu commands and states that each build and test command runs a Nix derivation.
- [ ] `design/README.md` (or its successor) adopts the six-section PDD template with a Test Cases section.
- [ ] The design lint passes.
