## What to build

PDD028, the `wasi:webgpu` test case. A generation test over the WIT that drives the owner's webview use case.

- A pinned copy of `wasi:webgpu@0.3.0-rc.2` (`wit/webgpu.wit` at `WebAssembly/wasi-webgpu` commit `6a776ba`) and its deps.
- An invocation with a `with` mapping for its 33 resources to types of a test module, and the `store` flag on `lost` and on `on-uncaptured-error`. Its async functions are resource methods.
- Compile the output on both targets, with stub trait impls that return `Error::Unsupported`-shaped host errors where a body is needed.

Before claiming coverage, check every return type of the WIT for `stream` and `future`, as the design did for `lost` (future) and `on-uncaptured-error` (stream).

## Acceptance criteria
- [ ] `wasi:webgpu` generates: the pinned WIT generates with a `with` mapping for its resources and the `store` flag on `lost` and `on-uncaptured-error`, and the output compiles natively and on `wasm32-unknown-unknown`.
- [ ] Without the `store` flag on `lost`, the build fails at the trait impl the test writes, which names `Access` (so the flag is shown to matter).
- [ ] `lint` passes, and `tests all` is green on both targets with the conformance summary unchanged.


## Delivery notes

Delivered on the host in `test(bindgen): Generate wasi:webgpu and run one host core under both macros`.

- The WIT is pinned under `rust/wcmp-bindgen-tests/wit-webgpu/` (`WebAssembly/wasi-webgpu` at `6a776ba`, with a README). Every return type was checked: only `[method]gpu-device.lost` (`future<gpu-device-lost-info>`) and `[method]gpu-device.on-uncaptured-error` (`stream<gpu-error>`) carry a future or a stream, and the WIT has no feature gates and no deps.
- `tests/webgpu.rs` generates it with all 33 resources mapped by `with` to unit structs of a host core, `store | trappable` on the two, and `default: trappable`, and implements `HostGpuDeviceWithStore<T>` (`lost`, `on-uncaptured-error`, and the three async methods) with stubs that return `Error::Unsupported`. It builds and runs on both lanes.
- Criterion 2 is a `compile_fail,E0407` doctest in `rust/wcmp-bindgen-tests/src/lib.rs`: without the `store` flag, an impl of `lost` in `HostGpuDeviceWithStore` that takes `Access` does not compile. Doctests run natively only (the `doctests` check).
