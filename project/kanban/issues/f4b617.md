## What to build
Define the four reserved kinds `StreamReadable`, `StreamWritable`, `FutureReadable`, and `FutureWritable` of `src/resource/handle_kind.rs`: each carries the identity of an end record in a store table, as a subtask entry carries a `SubtaskId`, and `WaitableId` in `src/concurrency/waitable_id.rs` names them. Add the store's two record tables (`src/concurrency/record_table.rs` is the pattern, one public type per module). The shared record holds the payload type, whether either end was dropped, and the pending side. The end record holds the waitable state of PDD018 (one pending event slot, the set the end joined, the synchronous-waiter flag), the copy state `idle | copying | cancelling | done` (the reference's `CopyState`), the direction, the index of its shared record, and a slot for the buffer of a copy in progress, which this card leaves empty. Build `stream.new` and `future.new` (`src/executor/translate.rs`, `src/executor/ir.rs`, `src/executor/instantiate.rs`, `src/executor/trampoline.rs`): both trap with the cannot-leave cause of PDD019 when the may-leave flag is clear, insert one shared record and two end records, insert the readable then the writable entry from the instance's allocator, and return `readable | (writable << 32)`. Build the four drop built-ins for an end that is not copying: trap with the cannot-leave cause; trap unless the entry's kind matches the built-in; trap on a writable future end that is not `done` with Wasmtime's `cannot drop future write end without first writing a value`; trap on an end whose copy state is not `idle` with Wasmtime's busy message per side and kind (`cannot remove busy stream` for a readable end, `cannot drop busy stream` for a writable end, and the two `future` forms); otherwise remove the entry, free its index to the instance's free list, leave the end's waitable set as the reference's drop does, mark the shared record dropped on the first drop, and free the shared record and both end records on the second. `waitable.join` (`src/executor/waitable_builtins.rs`) accepts an end, and `waitable-set.wait` and `waitable-set.poll` deliver an end's event once a later card fills it. Add `Error::Copy` with a structured `CopyCause` to `src/error.rs`, with the variants this card reaches, each carrying Wasmtime's message so the corpus matches it by substring; the payload-mismatch message is the polyfill's own. Later cards add their variants.

## Acceptance criteria
- [ ] `stream.new` and `future.new` return an `i64` whose low half is the readable index and whose high half is the writable index, both from the instance's allocator, proved by a repository test that reads the two indices.
- [ ] The components of `streams.wast` and `futures.wast` that define the two `new` built-ins instantiate.
- [ ] Dropping the first end marks the shared record dropped, and dropping the second end frees the shared record and its index, proved by a repository test that reads the store's records.
- [ ] Dropping a writable future end that has not written traps with Wasmtime's message, and every `new` and drop built-in fails with the cannot-leave cause from a realloc, each proved by a test.
- [ ] An end joins a waitable set through `waitable.join`, and dropping it leaves the set, proved by a test.
- [ ] `lint` passes and `tests all` is green on both targets, any async directive that starts passing has its line removed from the expected-failure list, and every line whose reason this card changes is refreshed from a live run.
