## What to build
The two registration-kind causes on `LinkError` (`src/error.rs` around lines 295-330) and the older `KindMismatch` carry `item: Option<String>` but none of their `#[error(...)]` strings renders it, so a link failure on an instance import with several function items reads `import <name>: ...` and never says which item. Wasmtime's chain inserts `instance export <item> has the wrong type` between the import context and the cause. Render the item when present, on every `LinkError` cause that carries one, and pin the rendered text in the tests that today assert only the struct field.

## Acceptance criteria
- [ ] A registration-kind failure on an interface import renders the item name, proved by a test that pins the full string.
- [ ] `KindMismatch` renders its item the same way, proved by a test.
- [ ] `lint` passes and `tests all` is green on both targets with the conformance summary unchanged.
