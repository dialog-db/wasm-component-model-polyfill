## What to build
The convention "no `pub(crate)`; control the API from `lib.rs` re-exports" cannot hide methods or fields on a re-exported type. `Store` exposes `context`, `store_data`, `store_data_mut`, `id`, `tables`, `tables_handle`, `lock_tables`, `scheduler`, `scheduler_mut`, `turn_in_flight`, `has_pending_work`, `turn`, `inner`, and `inner_mut` (`src/store/store.rs:69-137`), each documented as workspace-internal; `StoreContext` exposes `turn`, `nested_turn`, `run_in_turn`, `start_host_task`, `push_host_task`, `scheduler_mut`, `lock_tables`, `runtime_mut`, `register_resource`, `abandon_export_task`, and more. The values they return (`Scheduler`, `HandleTables`, `StoreData`, the runtime-layer store) are unnameable outside the crate but fully usable by method syntax. `ResourceHandle` has public `type_id`, `index`, and `rep` fields (`src/resource/handle.rs:31-45`), and `Instance` (`src/instance/instance.rs:78-108`), `Module::inner`, `CoreExtern::inner`, `CoreInstance::inner`, and `LinkerInstance::registration` are public too. Safe host code can therefore forge a handle and release it through `Store::resource_drop`, call `scheduler_mut().take_host_tasks()` from inside a `HostCall` and drop every pending host call, or run a turn from a trampoline; each is also a semver commitment. The reviewer of card `c723cc` flagged the same class for `Store::register_resource`.

Inventory every `pub` item reachable from the re-exports that the docs call workspace-internal, and bring the owner a decision on the convention: an internal crate the facade re-exports from, `#[doc(hidden)]` with a sealed marker, or allowing `pub(crate)` for exactly these. Then apply it, and make `ResourceHandle` opaque with accessors.

## Acceptance criteria
- [ ] The inventory and the owner's decision are recorded on this card.
- [ ] No method or field on a re-exported type reaches the scheduler, the handle tables, or the runtime store from safe host code, proved by a compile-fail doc test or an API snapshot test.
- [ ] `ResourceHandle`'s fields are private with accessors, or the decision states why not.
- [ ] `lint` passes and `tests all` is green on both targets with the conformance summary unchanged.
