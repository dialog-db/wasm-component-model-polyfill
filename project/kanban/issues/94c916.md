## What to build
A Rust-with-Rust composed baseline scenario for the Zena tests: the composition counterpart of scenario 14 (`rust-link-run-time`, card 6d91fb), from finding F4 of the independent review of card 2103de (landed as `278b47272`).

Every composed scenario (9, 12, 13) stops at `parse` on web and native, because of Zena's output, so nothing proves the polyfill runs a composed component to a pass. Scenario 14 already does this for run-time links: it has no Zena component, so the polyfill subjects run the partners and the link. A composed baseline does the same for `wac` composition.

- Add a scenario with a Rust importer and a Rust exporter, built as partners the way scenarios 10 to 14 build theirs (`tests/zena/partner.sh`), linked by a `composition` wiring line through `tests/zena/compose.sh`. It passes a string across the composition, untyped and typed. A composition is one component, so the contract may be sync.
- The greeting names the answering side, so a pass proves the call crossed the composition.
- Regenerate and commit the record lines.
- State the scenario in PDD024's integration table beside scenario 14, with the same baseline reasoning.
