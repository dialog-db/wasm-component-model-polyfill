## What to build
The linker refuses the root type import that a world-level `use` of an imported resource produces. A guest world that imports an interface with a resource and then `use`s that resource at world level gets a root import of the form `(import "request" (type (eq ...)))`. `linker/resolve.rs:410` (at `a0983522f`) treats a root `ResourceEquals` import as needing a root `request` registration, so instantiation fails with "no registered linker instance satisfies import request", even though the resource is already satisfied through the imported interface. Wasmtime resolves such an alias to the resource it names. The smoke card fed20f's `deadline` fixture exports an interface to avoid it.

Resolve an `eq`-bound root type import to the resource it aliases, as Wasmtime does.

## Acceptance criteria
- [ ] A repository test on both targets instantiates a component whose world `use`s an imported resource at world level, with only the interface registered on the linker.
- [ ] A root type import that names nothing registered still fails with a structured link error.
- [ ] `lint` passes and `tests all` is green on both targets.
