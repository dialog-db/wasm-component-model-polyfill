## What to build
Write the PDD for borrowed lifts of strings and lists: an equivalent of Wasmtime's `WasmStr` and `WasmList<T>` (`crates/wasmtime/src/runtime/component/func/typed.rs:1505, 1757`). A host function receives one of these in place of `String` or `Vec<T>`, and reads the guest's bytes in place with `to_str(store) -> Cow<str>`, `as_le_slice(store) -> &[T]`, `get`, or `iter`, instead of copying them into a host allocation.

**Why separate.** The typed-values PDD (911f20) keeps these out of scope. `bindgen!` never emits them (Wasmtime says so at `typed.rs:1485-1491`), and in the browser the runtime layer's `with_bytes` copies the range once anyway, so a borrowed view saves nothing there. The gain is native only, and it needs a runtime-layer borrow that outlives the closure `with_bytes` scopes it to, which PDD025 lists as a non-goal.

**Measured context (2026-10-15, `main` 97dc4609d, release, AMD Ryzen AI MAX+ 395, Chromium 154.0.8037.57, `target-sample-ms=50`, median µs):** typed `list-u8-roundtrip` at 65536 bytes is 5.06 on web and 4.29 native; typed `string-roundtrip` at 65536 is 7.24 web and 5.63 native.

The PDD must settle these questions:

1. **Worth.** Measure what a borrowed lift saves over the one-copy typed path on each backend (Wasmtime, Wasmi, web) and at what sizes. Decide whether the feature earns its API.
2. **Runtime layer.** What `wcmp-wasm-core` must lend: a slice with the store's borrow lifetime, and how that interacts with memory growth, shared memory (always copied today), and the browser's copy.
3. **Lifetimes and post-return.** Wasmtime now runs post-return inside `call`; say when a borrowed view stays valid for a host function parameter and for a `TypedFunc` result.
4. **Browser shape.** Keep Wasmtime's signatures (`Cow` for `to_str`, a slice for `as_le_slice`) or state each difference, given that the browser holds a copy.
5. **Copy budget.** How a borrowed read is charged.

The PDD follows `project/design/README.md`: plain English, the six sections, Goals and Non-goals that express scope, and Test Cases that a later card can lift as acceptance criteria. Do not name later PDDs.
