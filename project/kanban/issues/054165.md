## What to build

PDD027, "What a Val Costs" and "What It Costs". Add the benchmarks the PDD names to `rust/wcmp-bench`, and record their results with the conditions the PDD's measurement section lists (commit, machine, build profile, Chromium version, controls, median, and the 10th to 90th percentile).

- `list-record-roundtrip-typed/N`: the `echo-list-point` guest through `TypedFunc<(Vec<Point>,), (Vec<Point>,)>` with a derived `Point`, at 16, 256, and 4,096 records, beside the existing untyped `list-record-roundtrip/N`.
- `typed-acquire/<shape>`: `Func::typed` for a flat signature, a record of 16 fields, and a record inside a variant inside a list.
- `instantiate-typed-host/<n>`: instantiating a component whose `n` imports are `func_wrap` host functions over derived types, beside the same component with `func_new` host functions.

Update `rust/wcmp-bench/README.md`'s table. Run the web lane first, then native, one at a time, with `target-sample-ms=50`.

## Acceptance criteria
- [ ] The direct crossing is measured. `list-record-roundtrip-typed` runs on both lanes, web first, and is faster than `list-record-roundtrip` at every size on both lanes.
- [ ] The type check is measured. `typed-acquire` and `instantiate-typed-host` run on both lanes, and the card's review notes state each cost.
- [ ] Each recorded number carries its conditions: commit, machine, build profile, Chromium version, controls, median, and spread.
- [ ] `lint` passes.
