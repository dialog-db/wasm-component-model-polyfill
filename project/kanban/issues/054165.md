## What to build

PDD027, "What a Val Costs" and "What It Costs". Add the benchmarks the PDD names to `rust/wcmp-bench`, and record their results with the conditions the PDD's measurement section lists (commit, machine, build profile, Chromium version, controls, median, and the 10th to 90th percentile).

- `list-record-roundtrip-typed/N`: the `echo-list-point` guest through `TypedFunc<(Vec<Point>,), (Vec<Point>,)>` with a derived `Point`, at 16, 256, and 4,096 records, beside the existing untyped `list-record-roundtrip/N`.
- `typed-acquire/<shape>`: `Func::typed` for a flat signature, a record of 16 fields, and a record inside a variant inside a list.
- `instantiate-typed-host/<n>`: instantiating a component whose `n` imports are `func_wrap` host functions over derived types, beside the same component with `func_new` host functions.

Update `rust/wcmp-bench/README.md`'s table. Run the web lane first, then native, one at a time, with `target-sample-ms=50`.

- [x] Each recorded number carries its conditions: commit, machine, build profile, Chromium version, controls, median, and spread.

## Notes

- 2026-10-16: the benchmarks are in `rust/wcmp-bench/src/suite.rs` over the new guests `SHAPES`, `HOSTS_1`, and `HOSTS_16` in `guests.rs`.
  - `list-record-roundtrip-typed/N` clones a `Vec<Point>` into each call, as `string-roundtrip-typed` clones its `String`.
  - `typed-acquire` has a fourth case, `lookup`. `Func::typed` takes the `Func`, and the polyfill's `Func` is neither `Clone` nor `Copy` (Wasmtime's is `Copy`), so each iteration also runs `get_func`. `lookup` measures that call alone, so it can be subtracted.
  - `instantiate-untyped-host/N` is the `func_new` counterpart of `instantiate-typed-host/N`, at N = 1 and 16.
- 2026-10-16: conditions.
  - Commit e357f378d9aa, on an AMD Ryzen AI MAX+ 395 (32 threads, 94 GiB), Linux 6.18.52, release profile.
  - The web lane ran first, in headless Chromium 154.0.8037.57, then the native lane on Wasmtime.
  - Controls: warmup=16, samples=25, target-sample-ms=50, max-batch=10000000. The first web run used the default max-batch, which left `typed-acquire` capped below the clock floor, so the web figures below are from the second web run.
  - The machine was not quiet: the owner's desktop session was up (about 57 Chrome processes, load average 2 to 3.5).
  - Each figure is the median in microseconds per iteration, with the 10th-to-90th percentile spread as a percentage of the median in brackets.
- 2026-10-16: the direct crossing, `list-record-roundtrip` against `list-record-roundtrip-typed`. Typed is faster at every size on both lanes.

  | N | web untyped | web typed | native untyped | native typed |
  | --- | --- | --- | --- | --- |
  | 16 | 6.072 (8.5) | 3.294 (15.0) | 5.365 (1.4) | 2.227 (1.4) |
  | 256 | 50.375 (1.2) | 7.875 (9.2) | 76.823 (1.0) | 5.489 (0.3) |
  | 4096 | 752.308 (0.4) | 81.437 (1.2) | 1229.399 (0.2) | 56.283 (0.2) |

- 2026-10-16: the type check at acquisition, `typed-acquire`.

  | case | web | native |
  | --- | --- | --- |
  | lookup | 0.009 (3.9) | 0.017 (0.2) |
  | flat | 0.015 (0.9) | 0.038 (0.4) |
  | record-16 | 0.053 (0.8) | 0.064 (0.1) |
  | nested | 0.019 (0.8) | 0.039 (0.1) |

  Less the lookup, the check costs about 6 ns (web) and 21 ns (native) for `(u32,) -> (u32,)`, about 44 and 47 ns for a record of 16 fields, and about 10 and 22 ns for a list of a variant over a two-field record. It is paid once per `Func::typed`.
- 2026-10-16: the type check at link time, `instantiate-typed-host` against `instantiate-untyped-host`.

  | N | web typed | web untyped | native typed | native untyped |
  | --- | --- | --- | --- | --- |
  | 1 | 52.181 (34.1) | 51.786 (45.9) | 4.023 (0.3) | 4.077 (1.4) |
  | 16 | 51.750 (37.9) | 55.844 (58.7) | 4.795 (0.8) | 4.734 (0.7) |

  The typed host functions' check is not measurable against an instantiation into a fresh store.
  - Natively, 15 more imports cost about 0.7 to 0.8 us either way, and typed against untyped differs by less than 0.1 us at 16 imports, about 4 ns an import.
  - In the browser the spread (34 to 59 percent) is larger than any difference, so the web lane bounds the cost only from above, at a few microseconds for 16 imports.
