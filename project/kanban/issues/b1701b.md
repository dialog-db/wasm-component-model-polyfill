## What to build
Write the PDD for named imports of one interface under several names, `(implements "…")`, and Wasmtime's `named_imports` option (`crates/wasmtime/src/runtime/component/mod.rs:447-478` at `v49.0.0-rc.1`). Wasmtime generates an extra `Host` trait whose methods take a host-chosen id, and an `add_to_linker` that reads the component's `implements` annotations and calls a lookup per import. The codegen corpus entry `implements.wit` exercises it.

The design must settle whether and how the polyfill's parser and linker read the `implements` annotation, and how a registration is reached by plain import name.

## Acceptance criteria
- [ ] The PDD is formatted and passes the `markdown` check.
- [ ] It states the parser, linker, and generated-code changes, following Wasmtime.
- [ ] Its Test Cases cover two imports of one interface served by one host implementation distinguished by id, on both targets.
- [ ] The owner accepts the PDD before any implementation card is filed.
