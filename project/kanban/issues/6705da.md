## What to build
The review of the asynchronous-lower card named four edges its tests do not drive: a synchronous registration of a sync-typed import reached through an asynchronous lower resolves at once and returns `RETURNED` (`return_host_values` in `src/executor/trampoline.rs`); an asynchronous lower whose parameters spill past four flat slots (`parameters_spill(.., Async)` at `trampoline.rs:556`) is reachable but exercised by no test or directive; `waitable-set.poll` is never driven for a host subtask (only `waitable-set.wait` is); and the lowering item at `trampoline.rs:782` carries a second, weaker arity check beside the registration wrapper's (`linker_instance.rs:255-258`) that actually fires. Add a test for each of the first three, and either remove the duplicate arity check or reduce it to the wrapper's contract with a comment saying which one fires.

## Acceptance criteria
- [ ] A test proves a synchronous registration through an asynchronous lower returns `RETURNED` with no handle entry.
- [ ] A test proves an asynchronous lower with more than four flat parameter slots lifts them through the pointer and lowers the result.
- [ ] A test proves `waitable-set.poll` delivers a host subtask's event with the same triple `wait` delivers.
- [ ] One arity check remains, or the two are documented as one contract; `lint` passes and `tests all` is green on both targets with the conformance summary unchanged.
