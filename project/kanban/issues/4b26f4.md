## What to build

wit-parser 0.261 adds getter and setter functions. Wasmtime 50's `bindgen!`
refuses them with "unimplemented getter/setter". `wcmp::bindgen!` refuses them
too, with a compile error that names the function. As in Wasmtime, an
interface that `with` maps away is not refused.

`SizeAlign::fill` now returns a `Result`, and the generator returns its error
as a compile error. The copies of Wasmtime's macro sources move to `v50.0.0`,
and the `bindgen-pin` check reads the locked Wasmtime version.

Wasmtime 50 also added a codegen case with WIT types named `result` and
`option` (#14543). The generator already writes full paths for the prelude
types, so a test proves the case compiles.

This card lands in the same series as 2397ff. The workspace does not build or pass on Wasmtime 50 without it.

## Acceptance criteria

- [ ] Refusal tests cover a getter, a resource accessor, and a world whose
      accessors are all in `with`-mapped interfaces.
- [ ] The `bindgen-pin` check passes against the locked Wasmtime crates.
- [ ] A test expands an interface with types named `result` and `option`.
