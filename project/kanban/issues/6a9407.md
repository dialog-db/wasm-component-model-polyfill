## What to build
`Scheduler::enter_implicit_thread_in_switch_slot` in `src/concurrency/scheduler.rs` (around line 218) has a held branch — when the callee's instance is held, the task clears the switch slot and queues in arrival order — that no test exercises: every passing synchronous-lower directive enters through an open gate, and the existing gate tests cover `past_entry_gate` only. Add scheduler unit tests for the held branch: the slot is empty after the call, the task sits in the queue behind earlier arrivals, and it runs in arrival order once the instance is released.
