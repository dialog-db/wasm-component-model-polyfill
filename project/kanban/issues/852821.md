## What to build
Make the `resource.drop` trampoline of a local resource call the in-binary destructor synchronously with the dropped entry's rep, resolved against the core instances the plan produced before it. Admit a resource without a destructor. Surface a destructor whose core signature is not `(func (param i32))` as `InstantiationError`. Un-stub `it_supports_a_locally_defined_resource_with_an_in_binary_destructor` and make a handle from one instance fail to lower into another with the unregistered-resource-type ABI cause.

## Acceptance criteria
- [ ] `it_supports_a_locally_defined_resource_with_an_in_binary_destructor` passes on every target.
- [ ] A test proves the destructor runs exactly once per dropped handle.
- [ ] A test proves cross-instance handle confusion surfaces `AbiCause::UnregisteredResourceType`.
