## What to build
Expose a `ResourceType` value with an engine-issued identity and the destructor inside it. Widen `LinkerInstance::resource` to take a `ResourceType` beside the label, and keep the current one-liner as a convenience that mints one inline. Key the handle tables by the shared identity so a handle minted under one interface lowers through another. Un-stub `it_shares_a_single_resource_type_across_two_imported_interfaces`. Reconcile the stub `it_rejects_a_destructor_registered_against_a_mismatched_rust_type` with PDD013's non-goal on Rust type identity: retire or rewrite it in the same change.

## Acceptance criteria
- [ ] `it_shares_a_single_resource_type_across_two_imported_interfaces` passes on every target.
- [ ] The inline convenience still works for single-interface registrations.
- [ ] A mismatched identity at link time surfaces `Error::TypeMismatch` naming the interface and item.
