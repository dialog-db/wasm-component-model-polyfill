## What to build

PDD026, "The Drawer" (route edits) and "The Two Contexts: Boot" and "Messages".

- **Save.** The page writes the route source to IndexedDB and then sends `route-changed` with the pattern. The write completes before the message leaves. The service worker compiles the route at once and answers with `route-compiled`. On failure the old instance keeps serving.
- **Reset to original.** It removes the edit from IndexedDB, sends `route-changed`, and the service worker applies the shipped source.
- **Service worker start.** The service worker reads edited route sources from IndexedDB. An edited route that fails to compile falls back to the shipped source, and the drawer shows the edit and its diagnostics.

## Acceptance criteria
- [ ] A route edit applies in the service worker. A test changes a route's source in the drawer and saves. The next request gets the new behavior. After the service worker stops and starts again, the request still gets the new behavior.
- [ ] A route failure answers 500. A test saves a route that traps. The request gets 500, and the drawer shows the trap. The next request compiles the route again.
- [ ] A saved route that fails to compile leaves the old instance serving, and the drawer shows the diagnostics.
- [ ] "Reset to original" restores the shipped source. After an edit, a test resets the route. It behaves as shipped, and IndexedDB holds no edit for it.
- [ ] `tests all` and `lint` pass.
