## What to build
Give every boundary context (`src/abi/context.rs`) a copy budget: Wasmtime's default of 128 MiB per crossing, spent by the bytes of every value a lift builds, and a trap when it is spent with Wasmtime's message `too much data is being copied between the host and the guest: fuel allocated for hostcalls has been exhausted`, filed as a new `AbiCause` variant in `src/error.rs`. The design calls the concept the copy budget; only the message keeps Wasmtime's wording, so the corpus matches it by substring. Each list, string, and map lift in `src/abi/lift.rs` charges the count of its elements times the size in bytes of the host value type it builds, as Wasmtime charges the size of its `Val`. A crossing is one context, so one call into the host, one `task.return`, and later one copy has one budget. The budget must land before the stream and future copies do: `streams-massive-send.wast` writes a nested list whose layers alias one another, which no host can materialize, and without the budget the polyfill attempts it. This card does not touch that corpus file; the closing corpus card proves it.

## Acceptance criteria
- [ ] A synchronous call with a list result over the budget fails with the budget cause and Wasmtime's message, and a result under it succeeds, proved by a repository test.
- [ ] A string lift and a map lift charge the budget the same way, each proved by a test.
- [ ] `lint` passes and `tests all` is green on both targets, and any directive that changes outcome has its line refreshed from a live run.
