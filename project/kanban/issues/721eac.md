## What to build

After the switch (7eb780), every export call in the browser is a JSPI resumable call, and the web string and list benchmarks got slower. Each call costs about 3 µs more (u32-call 3.333 → 4.381 µs; string/64 4.158 → 6.800; list-u8-typed/64 3.889 → 6.333; list-u32/4096 78.0 → 120.5). With the host-suspension provider off, the web numbers match or beat the old baseline, so the whole cost is the host-suspension path. The owner waived the benchmark criterion on 7eb780 and asked for this card before the thread wraps.

Where the time goes, per the 7eb780 implementor:

- **Resumable call setup.** Each resumable call in `rust/wcmp-wasm-core-web` makes 3 `Closure::once_into_js` and 2 promise `then()` calls (`flight.rs` `watch()` and the release on drop), on top of `WebAssembly.promising`, even when the call never suspends. Set these up only once the call first suspends.
- **At-rest start.** The old provider ran a thread's start synchronously until its first suspend. Now the start becomes the store's flight: the turn returns `Resuming`, the driver awaits the flight under a `TurnGuard`, and a second turn collects the stop. A synchronous start path in the layer, or a fast path that finishes on the first stretch, would remove the second turn.
- **Finished recorder.** The entry wrapper's finished recorder is a host function behind the backend's generated wrapper, at 3+N+M wasm-bindgen crossings per call (see the 5d0ebe note on 7eb780).
- **Unexplained.** Most of `list-u32/4096`'s extra ~42 µs is unexplained: lowering and lifting run in the turn, outside the flight, and the list moves in one write and one read. Profile it.

## Acceptance criteria
- [ ] The string and list web benchmarks with the host-suspension provider on are the same or faster than the pre-switch baseline (`afc71435f`), and the card records both runs.
- [ ] A call that never suspends makes no JS closure and no promise hook beyond the ones a plain call makes; a test or a counter shows it.
- [ ] The `list-u32/4096` gap is explained, and closed or recorded.
- [ ] Native results do not get slower.
- [ ] `tests all` and `lint` pass.
