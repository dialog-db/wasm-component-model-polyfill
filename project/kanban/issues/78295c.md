## What to build
Make sure each menu command that builds or tests invokes a Nix derivation and nothing else: `build` produces the polyfill rlib for `wasm32-unknown-unknown` and the native target through `buildCrate`; the four test archives stay derivations; `lint` is `nix flake check`; the doctests run in a check. Remove any command that shells out to raw cargo for a build or test.

## Acceptance criteria
- [ ] `grep -n "cargo build\|cargo test\|cargo nextest run" flake.nix` shows only the archive replay inside `menuTestCommand`.
- [ ] `build debug` and `build release` print a store path.
- [ ] `nix flake check` covers clippy, rustfmt, doctests, the design lint, the Markdown check, and `project-lint`.
- [ ] A fresh clone runs `tests all` with no manual step.
