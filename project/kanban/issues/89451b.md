## What to build
Supply `wasi:cli/stderr@0.3.0` in the Zena test host, so the polyfill subjects provide every console import the pinned Zena emits.

The pinned Zena's console on the component target (`packages/stdlib/zena/console/component.zena:25-29` at `b2237f7`) imports `wasi:cli/stdout@0.3.0` and `wasi:cli/stderr@0.3.0`, both `write-via-stream: func(data: stream<u8>) -> future<result<_, error-code>>`, with `error-code` from `wasi:cli/types@0.3.0`. A program imports stderr only when it calls `console.error`; `wasm-tools component wit` on such a program shows `import wasi:cli/stderr@0.3.0`. The test host (`tests/zena/host.rs`) defines stdout, cli types and the clocks at the matching versions, but not stderr, so a Zena program that writes an error line stops at `link` on web and native. PDD024's Facts and Host Imports sections state the design.

- Define `wasi:cli/stderr@0.3.0` `write-via-stream` in the test host with the same behaviour as stdout: read the guest's stream into its own buffer and answer a future that resolves when the guest drops its end.
- Keep standard error apart from standard output. The runner compares only standard output with the Wasmtime run; standard error is not compared.
- Capture standard error apart in the Wasmtime run as well (`wasmtime-wasi` p3), so neither subject mixes it into the output lines.
- Make scenario 5 (console output) also write one error line through `console.error`, so its compiled component imports stderr. Its expected output lines do not change. Regenerate the record.
- Update the module doc of `tests/zena/host.rs`.

## Acceptance criteria
- [x] The test host defines `wasi:cli/stderr@0.3.0` `write-via-stream`, and a hand-written stand-in that imports stderr in the shape Zena emits writes to it and passes in the browser and natively.
- [x] Standard error is captured apart from standard output on every subject and is not compared.
- [x] Scenario 5's compiled component imports `wasi:cli/stderr@0.3.0`, its output lines are unchanged, and the Wasmtime run still passes it.
- [x] The record is regenerated and `tests zena` passes.
- [x] `tests all` and `lint` pass.
