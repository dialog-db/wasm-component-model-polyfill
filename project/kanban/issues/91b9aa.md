## What to build
`src/executor/waitable_builtins.rs:296-303` answers a poll of a set with no pending event with the none code and writes nothing, leaving the two words at the pointer as the guest left them. The reference's `WaitableSet.poll` returns `(NONE, 0, 0)` (`definitions.py:775-779`) and `canon_waitable_set_poll` always runs `unpack_event` (`:2367-2384`), which stores both words and traps on a misaligned or out-of-bounds pointer; Wasmtime's `waitable_check` writes zeros through the same bounds check on its none path. A callback export that polls an empty set with a pointer two bytes short of the end of memory traps in both references and returns 0 here; a guest that reads the payload after NONE sees stale words. Write `(0, 0)` through `write_payloads` on the none path so the pointer checks run.

## Acceptance criteria
- [ ] A poll of an empty set with a pointer two bytes short of the end of memory, and one with a misaligned pointer, each trap with the cause a wait raises for the same pointer, on both targets.
- [ ] A poll of an empty set with a valid pointer leaves two zero words at it.
- [ ] `lint` passes and `tests all` is green on both targets with the conformance summary unchanged.
