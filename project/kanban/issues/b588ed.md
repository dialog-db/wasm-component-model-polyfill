## What to build
Make the conformance harness measure each target with its provider and without one.

- The shared expected-failure list, `tests/corpus/expected-failures.txt`, records the best case: the failures under a provider.
- A new overlay, `tests/corpus/expected-failures.no-provider.txt`, lists the lines that fail without a provider. Each of its lines carries the stack-switch reason. The harness (`tests/conformance.rs`) applies it when the engine's provider query answers none. That covers a lane with the provider turned off, a native build on a platform without the proposal, and a browser without JSPI. The nested turn is one code path on both targets, so one overlay serves both. The web overlay keeps what only the browser does differently, and the harness applies both overlays when both hold.
- New lanes run the conformance corpus only, with the provider turned off through `EngineConfig`. `tests all` runs the corpus in all four states: native and web, each with and without the provider. The menu in `flake.nix` says so.
- `tests regenerate` writes the shared list from the native lane with the provider, and writes the overlay from the native lane without it.

No provider exists yet when this card lands, so both states of a target measure the same thing and the overlay starts empty. Later cards fill it. The owner reviews this set of lanes once the time each lane takes is known, so record the run time of each lane on the card.

## Acceptance criteria
- [ ] The harness applies `expected-failures.no-provider.txt` exactly when the engine's query answers none, and applies it together with the web overlay when both hold.
- [ ] The harness fails a run if a line of the overlay does not carry the stack-switch reason.
- [ ] `tests all` runs the corpus in all four states, and each state is green against its lists.
- [ ] `tests regenerate` writes the shared list from the native lane with the provider and the overlay from the native lane without it.
- [ ] The run time of each lane is recorded on the card for the owner's review.
- [ ] `lint` passes.
