## What to build
The owner asked for the Zena Playground's highlighting and language features in
the shelf, without the Node.js toolchain, and without building language features
that Zena lacks. The compiler component exports a `language` interface: Zena's
own language service and formatter, compiled in with the compiler. The shelf's
editor is a text area over a highlight layer (a Rust port of the Playground's
tokenizer) and a marks layer.

## Acceptance criteria
- [x] Live diagnostics: underlined and listed; a click on one moves the caret.
- [x] Hover shows the declaration, type, and doc comment.
- [x] Completion after a dot or on Ctrl-Space; Enter or Tab inserts.
- [x] F12 or Ctrl/Cmd-click goes to a definition, across tabs.
- [x] "Format" applies Zena's formatter.
- [x] The shipped sources show no problems.
- [x] Lane tests for each (demo lane 66/66); PDD026 and the demo README updated.
- [ ] `tests all` green: web release stalls 3 of 5 runs at 32 in flight with the
      larger compiler component (base 4 of 4 green; `-j 16` 4 of 4 green). See
      89afc4.

## Review notes
Completion answers from the last program Zena's parser could recover. A line
like `let x = this.` before another `let` does not recover, so completions there
come from the program before the edit. The Playground behaves the same way.
