## What to build
A component may import a core module and instantiate it inside (`(import "m" (core module ...))` followed by `(core instance (instantiate $m ...))`). The translator rejects the `InstantiateModule` initializer for an imported module at `src/executor/translate.rs` ("instantiation of an imported core module"). Wasmtime satisfies the import through `LinkerInstance::module(name, &Module)`. Add the same registration to the polyfill's `LinkerInstance` and root namespace, taking the polyfill-owned core module handle, and have the executor instantiate the registered module where the plan names it, with the imports the component supplies.

Parity: the registration is one API on both targets; the browser build compiles a module the host loads from bytes through the asynchronous path.

Corpus: 6 `deferred-feature` lines in `wasmtime/instance.wast`, `wasmtime/modules.wast`, and `wasmtime/nested.wast`.

## Acceptance criteria
- [x] A host registers a core module on the linker and a component that imports and instantiates it runs on both targets.
- [x] A missing module import is a link error naming the import, as for functions and instances.
- [x] Every `instantiation of an imported core module` line is removed from `expected-failures.txt`, and the corpus is regenerated.
- [x] `tests all` passes on both targets.
