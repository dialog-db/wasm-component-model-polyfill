## What to build
An import path may be longer than one item: the component imports an instance whose export is itself an instance holding the target item. Import resolution reads at most one path segment and rejects the rest at `src/executor/translate.rs` ("imports nested more than one level"). Wasmtime's `LinkerInstance::instance(name)` nests to any depth. Make the polyfill's `LinkerInstance::instance` nest the same way, resolve a multi-segment path through the nested registrations, and carry the nesting into the type projection so `Component::imports` describes it.

Parity: linker and resolution are shared code; add a cross-target test with a two-level import.

Corpus: 1 `deferred-feature` line in `wasmtime/instance.wast`.

## Acceptance criteria
- [x] A component importing `a` whose `b` instance exports `f` links against a registration made through nested `instance` calls, on both targets.
- [x] The `imports nested more than one level` line is removed from `expected-failures.txt`, and the corpus is regenerated.
- [x] `tests all` passes on both targets.
