## What to build

PDD027, "Resource Type Identity" and "Registration". `ResourceType` becomes the identity of a resource type, as Wasmtime's is (`crates/wasmtime/src/runtime/component/resources/ty.rs:44-62` at `v49.0.0-rc.1`), and absorbs `ResourceTypeId`.

- **The value.** `ResourceType` is `Copy + Eq`, and equality is identity only. `ResourceType::host::<T>()` keys it on the Rust type `T` (`TypeId`), `ResourceType::host_dynamic(u32)` on a payload. A guest resource keeps its per-instantiation identity (PDD012). `ResourceType` holds no name: today's label and index (`src/types/resource_type.rs:29-76`) and the label equality go. An error message names a resource by the name the component declares at the error's position.
- **Reflection.** `ValueType::Own` and `ValueType::Borrow` carry the identity, so two resources named `error` from different interfaces are different types everywhere, including `signatures_compatible` and `function_types_compatible`.
- **Registration.** `LinkerInstance::resource(name, ty: ResourceType, dtor)`, where `dtor` receives a mutable context for the store and the rep, as Wasmtime's `linker.rs:836-841` does. `HostResource<T>`, `resource_with`, and the identity-minting one-liner are removed. `check_shared_identity` (`src/linker/resolve.rs`) compares the new identity.
- **Callers.** Move every registration to the new form: the conformance harness (`tests/conformance.rs:870-876`), the smoke crate, the baseline tests, and the demo's `http_types`, which registers types at run time and moves to `host_dynamic`.

`ResourceHandle` and `Store::resource_new` stay for now, carrying a `ResourceType` in place of `ResourceTypeId`. A later card of this label replaces them.

## Acceptance criteria
- [x] A resource type value is an identity. Two calls of `ResourceType::host` with the same Rust type compare equal. Different Rust types, and two different `host_dynamic` payloads, compare unequal.
- [x] One resource type serves two interfaces. A host registers `ResourceType::host::<T>()` under two interfaces, a handle minted under one lowers through a function of the other, and the handle table holds one live entry for it.
- [x] A mismatched identity fails at link time with `Error::TypeMismatch` and a position that names the interface and the item.
- [x] Two interfaces each declare a resource named `error`, registered with `host::<A>()` and `host::<B>()`. Their `ValueType::Own` values compare unequal, and a handle of the first is refused when lowered where the second is declared.
- [x] `ResourceTypeId`, `HostResource`, and `resource_with` no longer appear in `public-api.txt`.
- [x] `lint` passes, and `tests all` is green on both targets with the conformance summary unchanged.
