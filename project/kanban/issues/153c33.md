## What to build
Add one variant to `Error` in `src/error.rs` for the scheduler, carrying a structured cause enum, and re-export the cause from `lib.rs` as `AbiCause` is. The four causes: deadlock, a driver went idle with its condition unmet, with the message Wasmtime prints for its deadlock trap; cannot block, a task that must not block went idle, with the message of Wasmtime's cannot-block trap; recursive driver, a driver was entered while another was inside a turn, or an accessor was used inside another accessor's closure; and stack switch needed, a guest thread blocked where the reference permits it and the target has no suspend provider. The last cause is not `Error::Unsupported`. The feature is supported and only the capability is missing, and a host wants to branch on it. Take the deadlock and cannot-block wording from Wasmtime 48's source (the `wasmtime` crate is a workspace dependency), so the conformance corpus matches by substring. The note in the library foundations about `anyhow::Error` applies. Nothing produces the variant yet. The scheduler, the `run_concurrent` entry, and the suspend seam produce it in their own cards.

## Acceptance criteria
- [ ] `Error` has one scheduler variant with a cause enum of exactly the four causes, both reachable through `lib.rs` re-exports.
- [ ] The deadlock and cannot-block messages are Wasmtime 48's trap strings, and a doc comment or test names where in Wasmtime they come from.
- [ ] A unit test per cause checks the rendered message, and one test shows the stack-switch cause is a different variant from `Error::Unsupported`.
- [ ] `lint` passes and the tests run on both targets.
