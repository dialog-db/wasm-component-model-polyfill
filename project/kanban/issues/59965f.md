## What to build
Replace `LiftContext` and `LowerContext` in `src/abi/context.rs` with one boundary context, the reference's `LiftLowerContext`, built per crossing from three things: the canon options of the lift or lower (memory, realloc, string encoding, and a data-model field that is linear memory today), the component instance, and the task or subtask whose borrows and lends the crossing counts against. The context selects an ABI strategy from its options. The eager strategy, which stores a value into linear memory the caller supplied or `cabi_realloc` returned and loads a value from a pointer, is the only one implemented; a second strategy, lazy or GC, sits beside it behind the same context. The context is the only object that reads guest memory, writes guest memory, or asks the guest for memory. Build one context at every crossing: `Func::call` for arguments and results, `invoke_trampoline` for a host call's arguments and results, and the adapter transcoder in `src/executor/intrinsics.rs`, whose `read`, `write`, `read_utf16`, and `write_utf16` helpers name memories and byte offsets today and must go through the context or move under `src/abi`. Nothing outside the lift and lower code names `cabi_realloc`, a memory, or a byte offset. A trampoline, an intrinsic, or the scheduler hands the context a value, a type, and a position, and reads back a value or a list of flat slots. Carry the options as a value on the context, and expose the lift options and the result type of the task on it, because a later `task.return` compares its own against them. An option the polyfill does not implement still fails at translation with `Error::Unsupported`.

## Acceptance criteria
- [ ] No call site outside the lift and lower code names `cabi_realloc` or reads or writes a guest memory; the review records the grep over `src/` that shows it.
- [ ] Every export call, host trampoline, and adapter intrinsic builds one context from options, instance, and task or subtask, proved by tests that exercise each path.
- [ ] The context carries a strategy selected from its options, and a test shows a second strategy can be selected without a change to any call site.
- [ ] `tests all` passes on both targets, and the conformance summary counts do not change.
