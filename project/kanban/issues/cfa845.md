## What to build

PDD026, "Elements: Failure".

- A trap poisons the tag's `Store`. The host framework then replaces the contents of each element of that tag with an error card: a short message that names the tag and the trap.
- A restart call in the host framework compiles the tag again and makes a new `Store` and instance. Each connected element of that tag gets `create` and `connected` again, with its current attributes, and renders. The drawer's "Restart" control calls this later.
- Elements of other tags keep working.

## Acceptance criteria
- [ ] A trap shows an error card. A test makes an element trap in `handle-event`. Every element of that tag shows an error card that names the tag and the trap.
- [ ] After a restart, the tag works again.
- [ ] An element of another tag keeps working through the trap.
- [ ] `tests all` and `lint` pass.
