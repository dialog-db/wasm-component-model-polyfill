## What to build

In Wasmtime 50, an adapter is inline only when the lower, the lift, and the
function type are all sync (`fact/trampoline.rs:176`). A sync lower into a
sync-lifted, async-typed export now goes through prepare and start call. So it
waits for backpressure and the exclusive lock, as the spec says
(`Task.enter_implicit_thread`, definitions.py `5b724da:420-442`).

The polyfill follows Wasmtime 49 here. `enter_sync_call` skips the gate for an
async-typed callee (`executor/intrinsics.rs:249-268`). That departs from the
spec the polyfill vendors. After this card the polyfill, the spec, and
Wasmtime agree.

## Acceptance criteria

- [ ] A sync lower of an async-typed sync lift waits at backpressure and
      exclusivity, returns its flat results, and runs its post-return.
- [ ] A sync caller whose callee blocks with no other thread to run fails with
      "cannot block a synchronous task before returning".
- [ ] `sync-lower-async-typed-entry-checks.wast` and
      `thread-transparency/reentrancy.wast` pass with their Wasmtime 50
      expectations.
- [ ] The async-typed branch of `enter_sync_call` is removed, or the code says
      which entry path still uses it.
