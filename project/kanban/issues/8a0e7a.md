## What to build
`lower_kind` (`src/executor/translate.rs:633-645`) fails `Component::new` for every `canon lower async` that lacks the `memory` option, and PDD020 (around line 148) states that rule as the design's. The reference requires `memory` only "if the Canonical ABI needs to load or store" (`Explainer.md:1421-1424`): for an asynchronous lower that is more than four flat parameters, which spill to one pointer, or a result, which always returns through a pointer (`flatten_functype` in `definitions.py`). Wasmtime accepts the memory-less shape, and the corpus has one: `wasmtime/async/cancel-host.wast:7` lowers `[method]resource1.never-return: func async (param "self" (borrow $r))`, one flat `i32` and no result, and `expected-failures.txt` lists it as `validation` with the reason "which the reference requires and Wasmtime does not enforce", which is not true for that shape. Require `memory` only when the flattened signature spills a parameter or carries a result; check that the asynchronous-lower trampoline tolerates a `None` memory slot on the path that never touches it; relabel the corpus line `deferred-feature` with the `subtask.cancel` reason it then fails for. The sentence in PDD020 is corrected by the design-reconciliation card, which should wait for this one.

## Acceptance criteria
- [ ] A component whose `canon lower async` names a function with at most four flat parameters and no result translates without `memory`; one with a result or more than four flat parameters is refused with the current message; both proved by tests.
- [ ] `wasmtime/async/cancel-host.wast:7` translates, and its expected-failure line carries the `deferred-feature` category with the `subtask.cancel` reason.
- [ ] `lint` passes and `tests all` is green on both targets with the conformance summary and the README baseline updated together.
