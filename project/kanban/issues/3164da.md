## What to build

Step 1 of the migration (build beside). Create `wcmp-wasm-core-wasmtime`, the Wasmtime backend of `wcmp-wasm-core`. It is the control: it runs beside the other backends so a person can compare results. This card covers modules, instances, externs, and host functions. Memory access and trap kinds are the next card.

This card also creates the **backend contract tests**: one set of tests, written against the `wcmp-wasm-core` trait only, that every backend runs (for example a `publish = false` crate that each backend's tests call with its own engine). The later backend cards run the same set. The tests must build for native and `wasm32`, because the browser backend runs them in the web lane.

- **Compile and instantiate.** Asynchronous compile and instantiation that finish at once, and a synchronous compile. Each compile returns its own module; the engine keeps no cache of modules by their bytes.
- **Boundary only.** The backend describes the imports and exports of a module and nothing else. A module is never refused for an item that does not cross its boundary.
- **Tags.** A tag is an extern kind. The host can import, export, and link a tag, and read its parameter types. The host cannot make a tag or throw.
- **References.** `funcref`, `externref`, and `i31ref` are readable. GC objects, `exnref`, and continuations are opaque: the host can hold one, test it for null, and give it back to a guest in the same store.
- **Host functions.** The closure is `Fn`, re-entrant at any depth, with its own arguments and results per call and a context that reaches the store. A host function that returns an error traps the guest with `Host(error)`, and no guest can catch it.
- **Capabilities.** Declare only what Wasmtime implements faithfully. Do not declare `host_suspension` (one store under `Func::call_async` has at most one suspended call). For `stack_switching`, only turn the feature on and let continuation types through.

## Acceptance criteria
- [ ] The contract tests exist in one place, are written against the trait only, and build for native and `wasm32`.
- [ ] A module that defines a global of a GC reference type and exports a tag instantiates on the Wasmtime backend, and the test calls an exported function.
- [ ] A module with an internal table of a concrete reference type, an internal tag, and an internal GC global, which exports one function, loads.
- [ ] A tag exported from one instance is imported into another. The host reads the tag's parameter types. A guest throws with the tag in one instance and catches it in the other.
- [ ] A host function calls into the guest, and the guest calls the same host function again. Each depth returns its own results.
- [ ] A guest calls a failing host function inside a `try_table` with `catch_all`. The call fails with `Host` and the host's own error, and the guest's handler does not run.
- [ ] The backend does not declare `host_suspension`, and its host-suspension methods return `Unsupported(host_suspension)`.
- [ ] `lint` and `tests native debug` pass.
