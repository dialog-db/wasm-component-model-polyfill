## What to build
A stream or future value in a parameter or a result is a readable end. Build the reference's `lift_async_value`, `lower_stream`, and `lower_future` inside the boundary context. Lifting (`src/abi/lift.rs`, beside `lift_handle`) removes the entry from the sender's table, traps unless the kind matches the type, traps with the payload-mismatch cause when the end's payload differs from the type's, and traps with Wasmtime's three lift messages per kind: when the end is `done` (`cannot lift stream after being notified that the writable end dropped`, `cannot lift future after previous read succeeded`), when the end is in a waitable set (`cannot lift stream while it's in a waitable set` and the future form), and when the end is copying. Lowering (`src/abi/lower.rs`) inserts a readable entry of the type's kind into the receiver's table. The index changes; the end record does not. Serve the `StreamTransfer` and `FutureTransfer` intrinsics the fused adapters of Wasmtime 49 call, one per value with the source index and the two types, as trampolines beside `ResourceTransferOwn` in `src/executor/intrinsics.rs` and `src/executor/translate.rs`: each lifts from the caller's table and lowers into the callee's table, as the resource transfer intrinsics of PDD015 move an owned handle. The result of `task.return` (`src/executor/task_return.rs`) crosses the same way. The writable end never leaves the instance that created it. A readable end that reaches the host through `Func::call`, or that a host passes into a guest, stays `Error::Unsupported` at the call until the host surface lands. The lift-after-done trap has no test here because no copy can reach `done` yet; the future copy card proves it.
