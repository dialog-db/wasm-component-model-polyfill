## What to build
Non-blocking findings (2)-(4), (6) and (7) from the review of card 5e6c63 (landed as `bc352c993`). Finding (1), the continuation memory growth, and (5), the stale no-provider wording, are carried on card 79456d.

- (2) The provider keys threads by `ThreadId.index()` and ignores the generation (`src/concurrency/stack_switching_provider.rs:190,206`; the finished map at `:26`). Key by the whole id so a reused index cannot reach a dead thread's continuation.
- (3) Resuming a thread that is not suspended fails as a generic substrate trap on a null continuation; `baseline/switch_module.rs:315` asserts only `is_err`. Return a structured error and assert it.
- (4) The vendored `Engine::default` fallback (`rust/vendor/wasmtime_runtime_layer/src/lib.rs:153-165`) discards the config error silently. Surface it (a log or a debug assertion) so a misconfiguration is visible.
- (6) Missing tests: a trap and a panic inside a continuation; an entry type with no wrapper; more than one shim or entry type (the `Layout` arithmetic for i>0); entries with zero or several results.
- (7) Doc lines over 100 columns at `src/store/store_context.rs:309,977`.
