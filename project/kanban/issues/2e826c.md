## What to build
Fixed-length lists (`list<T, N>`) are a value type of the current Component Model release and the outlook lists them as "Implement", with Wasmtime supporting them. The polyfill rejects them at the type projection ("fixed-length `list<T, N>` values"). Add the type to `ValueType` with its length, a `Val` shape, lift and lower per the canonical ABI (inline elements, no pointer and length pair), structural equality including the length, and a `ComponentValue` conversion for arrays so `TypedFunc` and `func_wrap` accept them. Mirror Wasmtime's `Val` naming.

Parity: the ABI is shared code; test in both lanes.

Corpus: `wasmtime/fixed_length_lists.wast:1` is the only vendored line; add a fixture built with `wasm-tools` from WIT so values are exercised, not just the type.

## Acceptance criteria
- [ ] A `list<u8, 16>` round-trips through an export and an import on both targets, typed and untyped, and a wrong length is a type mismatch.
- [ ] A fixture under `tests/corpus/fixtures/` exercises the type and passes in both lanes.
- [ ] `tests all` passes on both targets.
