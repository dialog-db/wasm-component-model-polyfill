## What to build
A hanging test stalls the gate instead of failing it. The review of card 88e273 found that if the nested turn stopped running work from other instances, `baseline_stream_copy`'s `PARKED_WRITER` test (`tests/baseline_stream_copy.rs`, around `:1008-1077`) would hang forever: the first sync read fails at once with the deadlock cause, but the test only unwraps that result after `run_concurrent` returns, and its second phase waits for two completions that never both arrive. The project sets no nextest timeout, so `tests all` would stall for as long as anyone waits rather than go red.

Two changes. First, make that test fail fast: bail out of the concurrent body as soon as the first read's result is an error, before the second phase. Second, give the test lanes a per-test timeout, so any future hang fails the lane with the test's name instead of stalling it. Nextest's `slow-timeout` with `terminate-after` in the repository's nextest profile is the usual tool; check how the `tests` menu command invokes nextest on both targets (the browser lanes run through `wbg-pool`), choose a limit well above the slowest current test, and make sure the timeout applies to every lane, native and web, debug and release. If a web lane cannot honour a nextest timeout, say how a hang there is bounded instead.

## Absorbed cards
The triage of 2026-09-26 merged these cards into this one and cancelled them. All six change the test lanes or the menu in `flake.nix` and the dispatch instructions. 6603fc and 78fd39 are the same request. Gate reliability comes first: a hang or a phantom failure wastes a whole sandbox run.

This card's own findings are the ones above, filed as "A hanging test fails the gate instead of stalling it". Each absorbed card's What to build and acceptance criteria carry over in full. Read them in `project/kanban/issues/<id>.md`:

- `917fba`: A web lane fails when wbg-pool cannot remove its browser profile
- `6603fc`: Say in the menu that a tests lane forwards its arguments to nextest
- `78fd39`: The tests menu says its trailing arguments reach nextest
- `675883`: Add a menu verb that formats the Rust sources
- `d09911`: Add a menu verb that refreshes Cargo.lock after a dependency bump

## Acceptance criteria
- [ ] With the nested turn limited to its own instance (a throwaway mutation), the `PARKED_WRITER` test fails within seconds, not after a timeout.
- [ ] A deliberately hanging test (throwaway) fails every lane of `tests all` with its name, within the chosen limit.
- [ ] The limit and why it was chosen are recorded where the nextest profile lives.
- [ ] `lint` passes and `tests all` is green on both targets.
- [ ] Every acceptance criterion of the absorbed cards (`917fba`, `6603fc`, `78fd39`, `675883`, `d09911`) is met.
