## What to build

PDD027, "Flags". The `flags!` macro with Wasmtime's syntax and generated API (`crates/component-macro/src/component.rs:1120-1517` at `v49.0.0-rc.1`), re-exported as `wcmp::flags!`.

```rust
flags! {
    Permissions {
        #[component(name = "read")]
        const READ;
        #[component(name = "write")]
        const WRITE;
    }
}
```

It emits one constant for each flag, `empty`, `all`, `contains`, `intersects`, `as_array`, the operators `|`, `&`, `^`, `!` with their assigning forms, `Debug`, `Default`, `Clone`, `Copy`, `PartialEq`, `Eq` (padding bits masked), and `ComponentType`, `Lift`, and `Lower` with a type check of count then names in order. It takes no crate path, as in Wasmtime.

## Acceptance criteria
- [ ] A flags type crosses through `flags!`. Flags types with 1, 8, 9, 32, and 33 flags cross in both directions on both targets.
- [ ] The test exercises each constant, `empty`, `all`, `contains`, `intersects`, and each operator.
- [ ] A flags type whose names or count differ from the component's fails the type check with a path to the flags type.
- [ ] `lint` passes, and `tests all` is green on both targets with the conformance summary unchanged.
