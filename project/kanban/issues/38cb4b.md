## What to build
With an item present, `LinkError::UnresolvedImport` renders `import a: instance export b has the wrong type: no registered linker instance satisfies import a` (`src/error.rs` around lines 424-433). The leaf clause is false in that case — a registered instance did satisfy `a`; only `b` is missing — and names `a` twice. Wasmtime's leaf for a missing item is `function implementation is missing` (or `module` / `resource`, per `matching.rs` lines 48-83). Give the item-carrying rendering a truthful leaf that names what is missing and its sort, keep the item-less rendering byte-identical, and pin both in tests. Add the end-to-end test the review named: register an empty `host` instance against the existing `IMPORTS_ITEM` fixture in `tests/baseline_linking.rs` so the missing-function site (`resolve.rs` around line 599) is reached from a component; and tighten the five `UnresolvedImport {{ .. }}` matches relaxed in the last card to pin `item: None` where the import is the item.

## Acceptance criteria
- [ ] A missing function, resource, and module item inside an instance import each render a leaf naming the missing sort, proved by full-string tests; the item-less rendering is unchanged.
- [ ] The missing-function site is reached end to end from a component and its rendering pinned.
- [ ] `lint` passes and `tests all` is green on both targets with the conformance summary unchanged.
